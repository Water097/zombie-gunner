## 第十一轮：敌人造型返工（"一个球"→ Q 版小人）

### 用户反馈（关键）
用户贴 Demo 截图对照概念图：「你自己看看这个僵尸和你画的概念图的僵尸一样吗？」——游戏里敌人就是"带高光的球"，结构完全读不出。

### 根因
一版把造型全塞进碰撞半径 r（普通僵尸仅 16px）：一个圆 + 高光点 = 球。概念图是"大头小身+脸+短手"的完整小人，信息密度差一个量级。

### 修复（只改 main.mjs）
- `ENEMY_VIS = 1.3`：视觉尺寸按碰撞半径放大（判定不变，仍 e.radius）
- 造型拆三层：`zombieBody`（衣服圆角矩形渐变）+ `zombieArms`（短手）+ `softBlob`（大头）+ `zombieFace`（发光眼+小嘴，twin 双脸给分裂尸）
- 各型对齐参考图：装甲=双头宽车体、远程=胸前抱球（篮球僵尸）、疾行=瘦削+身后速度线（鬣狗）、自爆=圆肚炸弹桶、飞行=软翼悬浮、蜂群保持小团
- 血条/状态环/受击闪白/攻击提示/要塞瞄准圈全部改按视觉尺寸 R 对齐
- 单测 211/211 全绿；浏览器实测（Edge）结构成立：头+发光眼+身体可读
- 提交 `1a876f5` 已 push

### 经验（勿再犯）
- **渲染验证必须用真实浏览器截图对照**，概念图好看 ≠ 游戏内成立；小尺寸造型先看"结构读不读得出"（头/脸/身三段），再谈细节
- 浏览器验证用 Edge 扩展（browser_id=2）；WorkBuddy 内置浏览器截图超 10MiB 上限
