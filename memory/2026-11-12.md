## 已完成（除「形态定稿」外）

- **弹体朝向**：`drawSkillShots` 只 `rotate(ang)`，而弹头画在**局部 -y**；要让它指向标准 atan2 角 `ang` 必须 `rotate(ang + π/2)`。朝上目标 `ang=-π/2` 时旧代码把弹头转成水平朝左 —— 就是用户看到的「水平于屏幕」。已修。
- **电磁天雷演出**：旧 `drawStrikes` 用固定 `arc(..., seed=7)` 画一条**不动的折线** + 只按 life 渐隐。改为按实例进度 `k = 1 - life/maxLife` 的四拍：闪现渐显(0~0.18，积云) → 落雷从云底向下**生长**(0.18~0.42，seed=`floor(time*60)` 逐帧抖动) → 命中白核+贴地椭圆电环+爬电(0.42~0.72) → 消失(0.72~1)。实机 280ms 就是「快」，实验室把 `flashMs` 拉长即可逐拍看清，渲染代码一份。
- **哨戒机枪口**：`aim` 原是 `-1.5 + sin(time*4)*0.8`（乱摆）。改成 `turretAim(world,t)`：优先读 `turretShots` 里最近该炮台的 `tx/ty`，否则取最近敌人，无目标朝上待机；弹道起点也从枪口出。
- **参数中心 `src/demo/lab-params.mjs`**：`labParams[id]` 从 `SKILLS` 全量拷贝（保留 color/name 元数据），`S` 是 Proxy 让 specs 里原写法 `SKILLS.xxx` 无缝变成 `S.xxx` 可编辑值；`weaponParams` 取 `DEFAULTS.player`（为此给 `tuning.mjs` 导出了 `DEFAULTS`）。`paramSchema()` 自动遍历全部数值字段生成滑块（9 技能 5~14 项、武器 10 项），`durationOf()` 统一按当前参数算循环时长，`cooldownMs` 可「冷却计入循环」并显示 CD 条。实验室参数**不写 localStorage、不影响实机**。
- **武器实验室**：`weapon-art.mjs` 从 `main.mjs` 抽出 `drawBullets`（实机与实验室共用），另加枪口焰/命中火花；`weapon-lab-specs.mjs` 跑真实**弹匣→开火→换弹**状态机（含双发纵列/散射/火爆弹头/穿透），HUD 显示弹匣/命中/累计/DPS/换弹条。`skill-lab.html` 重写：顶层「技能 / 武器」视图 + 右侧常驻参数面板 + 九宫格 + 冷却开关。
- **哨戒机 4 个可视化候选**：`turret-candidates.mjs` + `turret-options.html`，A 双管机炮塔（军用硬派）/ B 浮空哨戒无人机（科幻）/ C 棱镜激光塔（能量）/ D 重炮炮台（厚重）。拆 `base`（不转）/`head`（随 aim 转）两层，全部枪口固定对准正上方目标，只有后坐/枪口焰/充能。选择存 `localStorage['zombie-gunner.turret-choice']`。
