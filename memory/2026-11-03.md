## 第二轮：重型判定恢复 + 技能基础属性补齐（用户第 1/2 项）
### 用户纠正（重要原则）
- **"模型变大，碾压范围就该跟着变，符合物理定律"** —— 上一轮我做成"只放大模型、判定不变"是错的。
  用户原意是：旧设计「范围 +80%」太超模，不是"不该加范围"，而**加多少的问题**。现改成判定=模型尺寸（34×52 → 52×78，+18/+26px，面积 ×2.3）
- **"范围是本作最强属性"** → 范围卡的幅度必须谨慎（见下 B）
### 发现的两个硬缺口（比缺卡更严重）
- **干冰弹、温压弹根本没有直接伤害**！两者只施加冻结/灼烧状态，伤害全靠 DoT。与 02 册"伤害 299/溅射 249"差得远
- 已补：`SKILLS.freeze.dmg = 34`、`SKILLS.burn.dmg = 46`（均 ⚠️ 临时）；`hit/explode` 签名加 `world` 以便走 `dealDamage`（飘字/放大器一致）
- 温压修 bug：`hit` 里结算伤害 + `explode` 又结算一次 → 同目标吃两遍。改成 `hit` 空实现，伤害统一在 `explode`
### A：6 张基础属性卡（用户拍板 A+B 一起做）
- 干冰：冰锥强化（伤害+60%）、三连冰弹（数量+1，可叠2）；冷却卡已有
- 温压：高爆装药（直接伤害+60%）、快速装填（CD-25%）、双联装填（数量+1，可叠2）
- 装甲车：引擎预热（CD-20%）
- 数量卡实现：`castSkill` 一次多发、微散角 0.10rad（≈6°），起点沿射向 +6px 错开
- 卡池 38 → **44**（技能卡 21→27）；各技能卡数 2/2/7/10 → **4/5/7/11**（差距从 5 倍缩到 2.75 倍）
### B：范围卡降幅
- `燃料增量`（温压爆炸半径）30% → **20%**；`电场扩张`（电磁感电范围）30% → **20%**
### 难度补偿（技能补齐后必然变强）
- 补直接伤害后 smart 12/12、random 9/12（太简单）→ `DENSITY_COMP` 0.72 → **0.80**，回到 smart 8/12、random 5/12
- 锚点保持：第 3 波 6.0 / 第 9 波 12.0 / 第 19 波开始 18.3
### 工程：新增 serve.mjs（踩坑产物）
- 反复出现"改了代码、刷新还是旧版"：`python -m http.server` 不发缓存头，浏览器按 URL 缓存 `.mjs`
- 新增 `serve.mjs`：no-store + 端口参数；README/16 册改推荐 `node serve.mjs`，并把 python 标为"会缓存，慎用"
- 验证时用 8124（新 origin 绕开缓存）→ 面板确认 干冰4/温压5/电磁7/装甲车11
