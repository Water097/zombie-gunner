概念图库 · 像素风（pixelfx 内核）

全部改用 pixelfx 的硬像素画刷：1px 网格、4×4 Bayer dither、深→亮色阶、加色 light 缓冲、seeded 随机。本轮 demo 一行未改，先把概念图分门别类摆出来，你逐个调完再上实机。

载入中… → 打开 demo 实机
每个格子都是实时运行的 pure effect 模块，不是图片、不是截图。 它们和 pixelfx 自带 232 个特效走同一条 createFrame → createFx → composite → putImageData 管线；把模块从这里的 canvas 挪进 demo 的 render 循环，绘制代码一行都不用改。点击任意卡片可单独暂停对照。

上 demo 时还差什么（不吹「自动同步」）

  1. 宿主画布：demo 现在是 Canvas2D 路径绘制，像素缓冲要挂到一张离屏低分辨率画布，再 drawImage 整数倍放大进主画布；同时处理 DPR 与 image-rendering: pixelated。
  2. 绘制层级：draw(frame,"back") 放角色之后、draw(frame,"front") 放最前；角色/敌人本体要不要也改成像素缓冲，是个独立决定（本轮没动）。
  3. 时间驱动：demo 固定步长循环里加 fx.update(dt)；one-shot 用 fx.done() 回收，loop 用 fx.stop() 淡出。
  4. 坐标与生命周期：把 world.particles / rings / floaters / 击杀点 映射到局部原点，按事件挂 createFx。
