# 08 · 加成卡体系

> 本册定义：独立于「技能」和「武器」之外的第三族卡——**加成卡**。
> 你说的"这块会比较复杂"是对的，但它复杂的方向和你以为的可能不一样：
> 复杂点**不在卡的数量，在于它会不会把另外两族饿死**。

---

## 〇、先回答：为什么加成卡是个高危物种

假设有一张卡叫「攻击力 +20%」，无条件、作用于所有伤害。

那么无论玩家玩火、玩冰、玩电还是玩哨戒机，这张卡都成立。
而「高爆：深层冷却」这张卡，只有玩火的人才能用。

**在有限的 20 次选择里，永远通用 > 永远专用。** 数学上必然导出：

```
最优策略 = 先把所有通用加成卡点满，剩下的次数再挑技能
```

结果有三条，全是灾难：

| 后果 | 表现 |
|------|------|
| 技能被饿死 | 一局打完只填了 2 个槽，画面只有一种颜色，P2（构建可见）作废 |
| 每局长得一样 | 通用卡是同一批，玩家的 20 次选择有 6-8 次是固定的，每局的 Build 会长得一样 |
| 质变卡永远拿不到 | 质变在技能深处（第 3/5 级），次数被通用卡吃掉后就够不到了 |

**这不是理论风险，是这类游戏最常见的死法。** 所以加成卡不是"再来一批卡"，
它必须自带约束才能放进这个系统。三条约束，缺一不可。

---

## 一、三条约束

### 约束 1 · 定额预算（软上限）

```
一局最多拿 N 张加成卡（建议 N = 6）。拿满后，加成卡从当局卡池彻底消失。
```

**定额为什么降级为软上限**：在"每张卡必须带主语"（约束 2）成立之后，
带主语的卡本身就是专精卡，堆满也不会变成通用最优解。
所以它现在的主要作用是防止"20 次全点在加成卡上"的极端局，而不是防强度失控。

这一步把"无脑堆全"堵死。玩家必须回答的是"**我最想要哪 6 张**"，而不是"要不要拿"。

而且**预算要分层解锁**，否则玩家会在前 5 级一次到顶：

| 局内等级 | 可用加成卡预算 |
|---------|--------------|
| 1-6 | 2 张 |
| 7-13 | 再解锁 2 张（累计 4） |
| 14-20 | 再解锁 2 张（累计 6） |

### 约束 2 · 每张卡必须带主语（实测学到的，比限额更有效）

这个品类的正解不是"限额"，而是**每张卡都指明作用对象**（见 10 册第四节）。

| 对象层 | 例子 | 评价 |
|--------|------|------|
| ❌ 全局伤害 | 攻击力 +20% | **禁止**。它是通用最优解 |
| ✅ 带主语的伤害 | **子弹**伤害 +60% / **装甲车**伤害 +60% / **高能射线**伤害 +60% | **实测做法**。看起来像通用卡，其实每张都只管一条线 |
| ✅ 某一状态的目标 | 对冻结/燃烧/感电目标伤害 +25% | 主推。没点对应技能时它是废卡 |
| ✅ 某一时刻 | 换弹后前 5 发 +40% / 开局 10 秒 +50% | 主推。它创造"节奏"，不是纯数字 |
| ✅ 某一位置 | 防线 30 米外的目标 +30% | 主推。鼓励"远距离拦截"的打法 |
| ✅ 带代价 | 伤害 +30%，弹夹 -20% | 高手玩具，见第二节 |

**为什么"带主语"比"定额 6 张"更好**：
限额是"我允许你强 6 次，第 7 次不许"；带主语是"你强的那 6 次各自只管一条线"。
后者不需要玩家理解预算，也不需要 UI 解释——**它自己就是约束**。

**一句话判别标准**：
> 把卡面上的名词去掉之后，如果这张卡还能看懂，那它就是不合格的。
> 「子弹伤害+60%」去掉"子弹"变成「伤害+60%」——如果还成立，说明主语是装饰；
> 实际上它不成立，所以它是合格的。

### 约束 3 · 加成卡之间要记账（加算而非乘算）

同类型的多张加成卡之间**加算进同一个桶**，不是连乘。

```
❌ 乘算：(1+20%) × (1+20%) × (1+20%) = 1.728   ← 越叠越癫
✅ 加算：(1 + 20% + 20% + 20%)      = 1.60     ← 自带收益递减
```

这条不需要玩家理解，只要实现层这么算就行。
它让加成卡天然符合你认可的"武器递减"原则，不用额外配曲线。

## 二、加成卡的三类 + 规模预算

复杂度必须可控，否则你会做出 60 张互不相干的卡然后自己维护不动。
**总量封顶 24 张**，分三类：

### A 类 · 放大器（12 张）—— 主推，是"伪组合"

每张只奖励一种配合。玩家拿到它时会自动开始规划："我下个技能要不要选冰，好让这张卡生效？"
**这就是你要的深度，而且它是免费的深度——不需要新美术、新特效。**

| 卡（示意） | 作用对象 | 隐含要求 |
|-----------|---------|---------|
| 破冰 | 对冻结/减速目标 +25% 伤害 | 需要干冰弹 |
| 助燃 | 对燃烧目标 +30% 伤害 | 需要燃烧地带，或温压弹的「灼烧」 |
| 导电体 | 对感电目标 +20%，且感电可再传播一次 | 需要电磁穿刺 |
| 解剖学 | 对已损失 50% 血量的目标 +35% | 适合任何技能（这是少数安全的半通用卡） |
| 处决标记 | 血量低于 25% 的目标受到处决 | 配合高爆发 Build |
| 破绽 | 对同一目标的第 5 发起 +100% 伤害 | 奖励高频武器（冲锋枪 / 加特林） |
| 持续压制 | 连续射击同一目标时伤害递增 | 奖励单体 Boss 场景 |
| 交叉火力 | 场上敌人 > 15 时 +25% | 奖励清群 Build |
| 孤注一掷 | 场上敌人 < 5 时 +40% | 奖励单体 Build |
| 过载电容 | 感电状态的持续时间 +2 秒 | 让电磁穿刺的控场也成立 |
| 深寒核心 | 减速效果叠满速度加快 | 让干冰弹更快兑现质变 |
| 殉爆链 | 爆炸击杀会传递一次范围效果 | 温压弹专用放大器 |

⚠️ **命名纪律**：加成卡的名字不能和武器卡重名。
「稳定枪托」是加特林的专属物理参数卡（06 册 W5），加成卡这边改用「持续压制」。

### B 类 · 代价型（6 张）—— 高手的玩具

带明确负面的卡是给熟手的选择题，同时它们**天然免疫"通用最优解"问题**，
因为带代价就一定有人不要它。

| 卡（示意） | 正 | 负 |
|-----------|----|----|
| 高压弹仓 | 伤害 +35% | 弹夹 -25% |
| 轻量化 | 射速 +30% | 伤害 -15% |
| 独弹 | 每次射击只有 1 颗弹丸 | 单颗伤害 +150% |
| 近距离作业 | 射程 -40% | 伤害 +45% |
| 透支 | 每 10 秒损失少量要塞血量 | 伤害 +30% |
| 玻璃炮 | 要塞血量上限 -30% | 伤害 +40% |

### C 类 · 资源型（6 张）—— 不直接给伤害

它们改变的是"这一局你能做多少次选择"，是最安全也最有惊喜感的一类。

| 卡（示意） | 效果 |
|-----------|------|
| 快速学习 | 后续获得经验的速率 +20% |
| 军械配额 | 立刻 +1 次刷新机会 |
| 举一反三 | 下一次三选一变成四选一 |
| 前瞻 | 提前看到接下来两波会出什么敌人 | 纯信息，让玩家可以为 Boss 做准备 |
| 后勤补给 | 道具初始冷却 -20%（空袭 / 维修更早可用） |
| 军备竞赛 | 本局武器卡不再递减（取消递减，仅这一局） | 极端 Build 开关 |

> ⚠️ **「精华提取」（每波结束回血）已移除**：要塞回血不再绑定清波。改为「装备常驻回血词条（07 §4.2.1 头肩，随品级 2~6 血/s）＋ 低血触发的要塞急救功能卡（03 册第九节）」。后者是一局仅一次的 mercy 卡，不是每波白送。

## 三、它和另外两族怎么分工（伤害公式里的位置）

技能是独立攻击体系（见 02 册），所以总输出是**多条线求和**，不是一个大乘式。

```
总 DPS
  = 主武器线
  + Σ(每个技能各自的线)

其中：
  主武器线   = 武器基础 × (1 + 武器卡累计%) × (1 + 作用于子弹的加成%)
  技能_i 线  = 技能_i 基础 × (1 + 技能_i 的卡累计%) × (1 + 该技能挂上的易伤乘数)
```

| 族 | 加什么 | 影响哪条线 | 什么时候该拿 |
|----|--------|-----------|------------|
| 武器卡 | 枪的物理能力 | **只影响主武器线** | 开局前几次（这时候枪最便宜，见效最快） |
| 技能卡 | 某条技能线的成长 | **只影响对应技能线** | 全程一直在拿（**这是主干**） |
| 加成卡 | 跨线的放大器 | 跨线（但每张限定主语） | 看清自己 Build 之后再拿（通常中后期） |

**这个结构有两个好处**：

1. **不存在"武器卡 vs 技能卡互相稀释"** ——它们作用在不同的线上，是加法不是竞争
2. **"要不要开第 5 条线"成为一个明确的经济问题**：
   ```
   新开一条线 = 技能基础伤害 × (1 + 0 张卡) ≈ 很弱
   深化已有线 = 已有基础 × (1 + 更多卡) ≈ 更强
   → 玩家会自己算出"先深挖，后期再开新线"
   ```
   实测玩家正是这么做的（2 个技能深挖到 5-7 级，4 个槽只用了 2 个）。

**理想的玩家叙事应该是**：
```
开局几次 → 喂枪（伤害立刻见效，爽）
中段     → 把 1-2 个技能推到能打（画面开始有颜色）
中后段   → 用加成卡把已有线撬起来（Build 兑现）
终局     → 冲最后一个质变点
```

如果实际玩起来玩家的路线和这条不一样，说明曲线配错了，不是玩家错了。

## 四、三选一的组成规则

```
3 张卡的组成
  ├─ 至少 1 张「已学技能的强化卡」        ← 硬保底（见 03 册）
  ├─ 另外 2 张从「武器卡 / 加成卡 / 新技能入门卡」中出，且不会同时同族
  ├─ 新技能卡受 03 册停发公式约束：剩余次数 < 3 × 未成型技能数 + 4 时不再出现
  └─ 加成卡只在预算未耗尽时出现
```

**保底为什么是"已学技能的强化卡"而不是"新技能卡"**：
它保证的是「深挖」这条路永远有卡可选，不是让玩家填满 4 槽（4 槽是上限不是目标，见 02 册第四节）。

## 五、规模总账（防复杂度失控）

| 族 | 张数 | 备注 |
|----|------|------|
| 技能卡 | 9 技能 × 6 维 ≈ 54 张（第 1 章） | **当局池只出已学技能的卡**（通常 2-3 个，约 12-18 张） |
| 武器卡 | **每把枪 3 张**（6 个型号 = 18 张，但一局只见到当前枪的 3 张） | 叠满 6 级即止（见 06 册二·五） |
| 加成卡 | **24 张**（12 + 6 + 6） | **封顶，不再增加** |

**加成卡封顶是本册最重要的一条纪律。** 它是最容易源源不断加内容的卡族，
因为每张都很好做。但它每多一张，另外两族的曝光就少一次。

> 用户后续要加内容时：**加技能，不要加加成卡。**
