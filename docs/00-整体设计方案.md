## 一、一句话定位

**玩家在战场外做 20 次决定，偶尔伸手进战场改写一个目标。**

瞄准、开火、换弹、道具默认全自动；玩家可随时接管指向，松手 2.5 秒后回落托管。
所以游戏质量 = **卡池质量 × 抽卡规则 × 20 次选择的节奏**，手动瞄准只是补丁。

## 二、五条设计支柱

| # | 支柱 | 含义 | 用来否决什么 |
|---|------|------|------------|
| P1 | **决定即全部** | 主输入是选择，所以每个选项必须有肉眼可见的分量 | 否决"全是 +10% 小数的卡"、否决"允许跳过选卡" |
| P2 | **构建可见** | 每个技能一个独占主色，卡面 / 弹道 / 命中特效三者同色 | 否决看不出效果变化的卡 |
| P3 | **局内优先** | 一局的强弱 75% 由局内 20 次选择决定（局外占 25%） | 否决**无界**局外攻击力（框在 ×2.0）、否决武器局外升星 |
| P4 | **长局可续** | 7 分钟一局，必须能中途续上 | 否决无存档的长局 |
| P5 | **随手可撒手** | 任何时候把手拿开，游戏都必须能通关 | 否决"必须一直点屏幕"的一切设计 |

## 三、单局流程

```
[选关] → [20 波连续战斗，约 6-7 分钟] → [结算]
              ↓ 每升 1 级（共 20 次）
           [暂停 · 三选一 · 选 1 张卡]
```

| 阶段 | 波次 | 玩家在想什么 | 系统在做什么 |
|------|------|------------|------------|
| 起手 | 1-3 | "这游戏挺轻松" | 密度低，让玩家完成前 3 次选择 |
| 成形 | 4-8 | "我要养哪条线" | 引入新敌人（波 7 首次蜂群），开始有压力 |
| 高压 | 9-15 | "有点顶不住了" | 密度陡增，这段是手动接管的主战场（波 13 蜂群） |
| 清算 | 16-19 | "满屏都是我的特效" | 密度最高，Build 全部兑现（波 17 蜂群） |
| 收尾 | 20 | 第 5/10 关："打掉 Boss"；其余关："撑住就赢了" | 尸墙（最厚混合尸潮）或 Boss |

**波与波之间没有停顿。** 靠四个信号感知换波：波次数字跳动 / 敌人种类换一批 / 音乐层切换 / 屏幕边缘扫光。

## 四、三条核心取舍轴

### 轴 1 · 喂枪 vs 养技能（抢同一个资源）

```
20 次升级
├── 最多 6 次投给枪（武器卡池到 6 级封顶）
└── 其余 12-14 次投给技能与加成卡
```

**武器等级 = 你投了几张武器卡**（右上角那个「6 级」就是这个意思）。
枪先便宜（见效快），到 6 级抽完即止——这个"抽完"本身就是信号：**该补技能了**。

### 轴 2 · 深挖 2 条 vs 铺开 4 条

```
深挖：2 个技能各 5-7 级 → 拿到质变卡，画面只有两种颜色，但每条线都很狠  ← 甜区
铺开：4 个技能各 1-2 级 → 拿不到质变，四种颜色都有，但每条都很软       ← 隐性陷阱
```

**4 个槽是上限，不是目标。** 每个技能有起步价（3 张成型），学新技能的真实成本是 3 张卡。
抽卡规则 `剩余次数 < 3 × 未成型技能数 + 4` 会自动停止发新技能卡，把玩家推进甜区。

### 轴 3 · 打面 vs 打点

```
温压弹 / 燃烧地带 / 旋转刀轮 → 清群，但打单个厚目标是浪费
电磁穿刺 / 装甲车 / 高能射线 → 纵向或持续强，但侧向覆盖差
```

第 20 波尸墙检验"打面"；Boss 检验"一边清场、一边抽资源打高价值目标"。

## 六、已决定清单（这是"我们定了什么"的主表）

### 6.1 战斗与操作（01）

| 项 | 定案 |
|----|------|
| 自动系统 | 瞄准（锁最近）/ 开火 / 换弹 / 道具，全部自动 |
| 手动接管 | 按下即接管，**只认第一个触点**；松手维持 **2.5 秒**回落 |
| 手动的边界 | **只能解决"打错人"，不能解决"打得不够狠"** |
| 准星 | 画在触点上方约 40px；用**方向角**而非精确点选（可在空白处操作，不挡视野） |
| 换弹 | 1-2 秒，期间不可开火、不可被打断、手动不绕过 |
| 验收标准 | **全程不碰屏幕必须能通关第 10 关**（普通难度） |

### 6.2 技能（02）

| 项 | 定案 |
|----|------|
| 模型 | 技能 = 独立攻击体系：自己的攻击方式 / 数值 / debuff / 升级树（不再叠在同一颗子弹上） |
| 名单（9 个） | 温压弹·火·清群 / 干冰弹·冰·拖延 / 电磁穿刺·电·打队列 / 装甲车·物理·击退守线 / 高能射线·能量·持续 / 制导激光·能量·扇面扫射 / 哨戒机·覆盖兜底 / 燃烧地带·封锁地面 / 旋转刀轮·横向清越线 |
| ↑ 后 3 个（哨戒机/燃烧地带/旋转刀轮）为覆盖型技能，由设计补全以补齐怪物覆盖率，待用户确认 | |
| 升级树 | **20 级具体解锁树**：基础数值 + 每级增幅 + 2/6/10 级解锁选项（参考 video；Excel 还列 12/15/18/20 级强化，以实机为准） |
| 升级资源 | **金币 + 技能碎片**（通关掉落；video(4).mp4 升级界面实机确认） |
| 升级奖励 | 每技能账户级「暴击伤害增幅 **+0.30%/级**」（原 Excel +1.0%，2026-10-30 Monte Carlo 校准后下调）——局外攻击加成，进 ×2.0 账（见 07 七·五） |
| 两条硬纪律 | ④易伤必须写"不可叠加"；每张卡必须有主语 |
| 槽位 | **上限 4，实际甜区 2-3**（不变） |
| 正确投法 | 9 个技能各不相同（02 册对照表），这是"选择 > 深度"的落地 |

### 6.3 卡池与升级（03）

| 项 | 定案 |
|----|------|
| 三族 | 武器卡（不占槽）/ 技能卡（占槽）/ 加成卡（不占槽，软上限 6 张） |
| 保底 | **三张里至少 1 张是"已学技能的强化卡"**（保证深挖永远有路） |
| 停发新技能 | `剩余升级次数 < 3 × 未成型技能数 + 4` → 卡池不再出现「学习新技能」 |
| 叠层 | 数值/范围型 2 层；行为型（质变）1 层；入门卡 1 层 |
| 刷新 | 每局 1 次免费，**不做广告** |
| 卡面 | 主语 + 效果 + 数字 + 叠加规则；新技能打「新」角标 |

### 6.4 关卡与波次（04）

| 项 | 定案 |
|----|------|
| 单局 | 20 波连续，无波间停顿，单波 18-21 秒，全局 6-7 分钟 |
| 出怪区 | **顶部一横条，绝不超过中线**；中线 = 可见警戒线 |
| Boss | **每 5 关一个**：第 5 关（中期）、第 10 关（章末）。其余关第 20 波为尸墙 |
| Boss 四条约束 | 持续召唤杂兵 / 散布空间 / 血量不能打不动 / **不免疫任何控制** |
| 自动瞄准 | **永远锁"最近"，绝不自动优先 Boss**（否则手动失去价值） |
| 难度曲线 | 以**密度为主、血量为辅**；逐关显式系数，不用公式 |
| 精英难度 | **做**。只动关卡不动 Build |
| 手动教学 | 第 1-3 关用场景引导（远程兵停在出怪带最上沿），**不弹任何提示** |

### 6.5 敌人（05）

| 项 | 定案 |
|----|------|
| 数量 | **8 种**：普通兵 / 疾行兵 / 自爆兵 / 远程兵 / 装甲兵 / 飞行兵 / 分裂兵 / **蜂群** |
| 覆盖率 | 9 个技能，覆盖率需按新名单重算（05 册二·五表；后 3 个覆盖型技能正是为补缺口而加） |
| 蜂群 | 只在波 **7 / 13 / 17** 出现（检查点）；单次 8-12 只；血量 = 普通兵 15%；**死亡不产尸爆** |
| 三条写死的属性 | 装甲兵**抗击退 ×25%**；装甲兵**减速幅度 ×50%**（时间不打折）；飞行兵**只有后 30% 路程进哨戒机射界**（仰角上限 35°） |

| 台词 | 首版只做 3 种（普通兵 / 自爆兵 / 精英怪），每句 **≤ 12 字** |

### 6.6 武器与换弹（06）

| 项 | 定案 |
|----|------|
| 结构 | **型号（6 把）× 品级（6 档）正交**，不做 36 把枪 |
| 型号 | 突击步枪 / 冲锋枪 / 霰弹枪 / 精确步枪 / 榴弹炮 / 加特林 |
| 六桶 | W1 常驻 / W2 装填 / W3 远距 / W4 近距 / W5 持续 / W6 首发。**每把枪只有一个主场桶** |
| 状态桶 | **移出武器侧**（归入技能侧，主语是技能） |
| 卡池容量 | **每把枪 3 张卡 = 6 级封顶**（常驻 ×3 + 条件 ×2 + 参数 ×1） |
| 换弹惩罚率 | 加特林 7.7% < 突击 8.1% < 霰弹 9.7% < 冲锋 16.1% < 精确 16.7% < **榴弹 24.2%**。**排序不许改** |
| 暴击 | m = 1.3-1.5；**R1** 暴击率只由武器决定（5-15%）；**R2** 卡池卡只定义"红字时发生什么"；**硬上限 25%** |
| 稀有度 | 普通(白) / 精良(蓝) / 稀有(紫) / 史诗(粉) / 传说(**金**) / **灾厄(赤红+黑纹)** |
| 全局基准 | 所有武器共享随进度抬升的基准；敌人血量按同一基准缩放（跑步机） |

### 6.7 局外养成（07）

| 项 | 定案 |
|----|------|
| 纪律 | **局外可以给攻击力，但框在输出侧 ×2.0 内**（来源：技能升级奖励 + 装备攻击词条 + 品级 + 等级） |
| 输出侧上限 | **×2.0**（占比 25%）。分配：武器品级 **×1.30** × 等级 ×1.10 × 技能奖励 **×1.114** × 装备攻击词条 **×1.20** ≈ **×1.92**（2026-10-30 独占校准＋账本重分；技能奖励每级 +0.30% 已拍板，余量留给强化/镶嵌） |
| 生存侧 | 不计入 ×2.0（它不改打法），另有一条独立的账 |
| 装备 | **6 个部位**，每部位独立词条池**可含攻击**（video：攻击+10 / 各系伤害+6~8% / 技能系数+10%）；**强化/镶嵌延后** |
| 玩家等级 | 主要作用是解锁内容，解锁节奏 = 教学节奏 |
| 存档 | SaveAdapter 抽象层 + 本地实现；**本期不接服务端**（后续接 D1，见 07 七） |
| 不做（本期） | 体力 / 广告 / 抽卡开箱 / 装备强化 / 宝石镶嵌 |

### 6.8 加成卡（08）

| 项 | 定案 |
|----|------|
| 三条约束 | ① 软上限 6 张（分层解锁 2/4/6）② **每张必须带主语** ③ 同桶加算不连乘 |

### 6.9 收益曲线与伤害公式（09 / 11）

| 项 | 定案 |
|----|------|
| 武器侧 | 形态 C 里程碑锯齿（递减是加算桶的数学必然，不需要人为配衰减系数） |
| 技能侧 | **六格分配模型**：收益由"投在哪几个格子"决定，不由深度决定 |

| 已知坑 A | 广铺技能是隐性陷阱 → 起步价 + 成型度 UI + 铺开警戒 |

## 七、五条硬规矩（改动设计前先看这五条）

| # | 规矩 | 边界 |
|---|------|------|
| 1 | 手动接管只改目标，不改输出 | 验收：不碰屏幕能通关第 10 关 |
| 2 | Boss 平衡：普通难度不手动能过但很险（剩余血量 <30%）；精英难度手动是必需 | 自动瞄准**永不自动优先 Boss** |
| 3 | 每张卡必须有主语 | 去掉名词后仍能看懂的卡 = 不合格 |
| 4 | `剩余次数 < 3 × 未成型技能数 + 4` → 停发新技能卡 | "未成型" = 等级 < 3 |
| 5 | 局外输出侧 = **×2.0**（占比 25%，**可含攻击力**，框在四来源内） | 分母（终局 ×5.0）写死；> 40% 即失控 |

# 附录 A · 已否决的方案与理由

> 这些是**我们明确否定过的设计**，记在这里是为了避免重复踩。
> 它们不再出现在任何分册的正文里。

| 被否决的方案 | 否决理由 | 现在是什么 |
|------------|---------|-----------|
| **技能 = 改造子弹属性**（火/冰/电挂同一颗子弹） | 录屏推翻：装甲车、高能射线是独立单位/光束；4 个技能同时挂一颗子弹会让画面糊成一团 | 技能 = 独立攻击体系，各算各的线 |
| **通用加成卡「攻击力 +X%」** | 它是无条件最优解，会饿死所有技能，让每局长得一样 | 每张卡必须带主语 |
| **加成卡定额 6 张（硬上限）** | 限额需要 UI 解释；带主语之后它自己就是约束 | 降级为软上限，主要防极端局 |
| **完美换弹**（换弹条上点中窗口则减半） | 手动瞄准和完美换弹是两个独立手动点，同时存在会让游戏方向模糊 | 只保留手动瞄准；换弹问题交给 Build |
| **第 20 波无 Boss / Boss 只在章末** | 取样偏差：参考只录了前两关，后面每 5 关有 Boss | **每 5 关一个 Boss**（第 5/10 关） |
| **Boss = 纯单体高血量** | 铺面 Build 会在最后一分钟突然失效，那不是难度是背叛 | Boss 四条约束（召唤 / 散布 / 不厚 / 不免疫控制） |
| **Boss 波自动优先锁 Boss** | 玩家不需要手动了 → 手动失去价值 → 精英难度那条落空 → Boss 战退化成站着看 | 自动永远锁最近 |
| **技能收益随深度递增 + 质变点** | 实测："进化为重型装甲车"第 2 张就来且只给 50%；真正决定收益的是投在哪个已铺开的乘数上 | 六格分配模型 |
| **武器数量 36 把**（6 型号 × 6 稀有度） | 每把都要调参、平衡、画图标，工作量不可接受 | 型号 × 品级**正交** |
| **稀有度「史诗(金)」排在「传说(橙)」之上** | 与玩家认知反了（主流 loot 里金/橙都被认作最高档） | 传说 = 金，灾厄 = 赤红+黑纹 |
| **卡池里的裸暴击率卡** | 玩家会去堆暴击率，回到"堆数值"；且低倍暴击纯加伤害时是陷阱卡（m=1.35、c=50% 时期望仅 ×1.175，不如一张 +30%） | R1：暴击率只由武器决定；R2：卡池卡带 attach 效果 |
| **装备 9 个部位** | 9 个互不相干的格子不产生取舍，只产生比较疲劳 | 压到 6 个部位 |
| **装备给无界攻击力** | 会压扁 Build，3 选 1 退化成随便点 | 装备主轴生存/节奏/机会；可含**有界攻击词条**（计入 ×2.0，2026-10-30 反转）；首饰给"局内机会" |
| **局外 ×2.5**（A：局内压到 ×2.0 / B：敌血 ×1.2） | A 抢局内的账（与"选择 > 深度"打架）；B 要全局重配敌血。**×2.5 的养成感必然由局内或敌血之一买单** | **×2.0**，两个代价同时消失 |
| **可叠加的易伤** | 堆 3 个易伤 = ×1.95，"叠易伤"会变成唯一最优解 | 易伤必须写"不可叠加" |
| **强制填满 4 槽**（第 13 级起强制出新技能） | 实测打脸：深挖 2 个才是最优，强制填满会塞一堆废卡 | 4 槽是上限不是目标 |
| **状态桶放在武器侧**（对冻结目标 +X%） | 它的前提是技能 Build；混进武器桶会出现"没点干冰弹时 1/3 卡池是废卡" | 状态类卡归入技能侧 |
| **治疗兵 / 召唤师 / 光环兵列为禁区** | 那是纯自动瞄准时代的红线 | 手动接管让"必杀类"敌人重新可用（但不做"漏杀一次就输"） |
| **体力 / 看广告 / 抽卡开箱** | 没有商业化诉求，它们只会碍事 | 全部不做 |
| **第 1 章就接服务端数据库** | 玩法还在改，schema 变更成本比纯前端高一个数量级 | SaveAdapter 抽象层，本期只做本地实现 |
