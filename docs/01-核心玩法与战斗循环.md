# 01 · 核心玩法与战斗循环

> 本册定义：玩家做什么、单局怎么走、什么算赢什么算输。
> 不涉及数值（比例、阈值），只定结构与规则。
>
> **核心是「半自动瞄准」**：默认托管，玩家可随时接管指向。
> 这不是把操作加回来，是给玩家一个**只在关键时刻用**的工具。

---

## 一、一句话定位

**玩家在战场外做 20 次决定，偶尔伸手进战场改写一个目标。**

瞄准、开火、换弹、道具默认全自动。玩家的输入有两种：
① 每升一级的那次三选一（主要）；② 手动接管指向（次要、可选、有时限）。

所以这个游戏的质量 = **卡池质量 × 抽卡规则 × 20 次选择的节奏**。
手动瞄准是**补丁**，不是第二条玩法线。

这条决定了后面所有设计的主次：
**任何要求"持续手速"的设计都是错的；任何让手动接管"值得"的设计都是对的。**

---

## 二、战场结构

```
┌──────────────────────────┐
│  敌人从上方涌入（3 条通道 + 空中）  │
│                          │
│        ↓ ↓ ↓             │
│                          │
│   ┌──────────────┐       │
│   │   要塞防线     │       │  ← 僵尸越过这条线 = 扣要塞血量
│   └──────────────┘       │
│                          │
│     [角色] [武器]  ← 固定在底部，默认自动瞄准+自动开火
└──────────────────────────┘
```

| 元素 | 规则 |
|------|------|
| 角色位置 | 固定底部中央，**不可移动**（移动会引入走位操作，与"随时可撒手"冲突） |
| 射击目标 | 默认自动锁定**最近的敌人**；玩家接管时指向由玩家决定 |
| 开火 | 有目标即开火，无目标停火（弹药不消耗） |
| 要塞血量 | 单局内唯一的失败资源；僵尸越过防线即扣血 |
| 波次推进 | 20 波连续，**波与波之间不暂停**，计数器递进 |

---

## 三、单局时间轴

| 阶段 | 波次 | 玩家在想什么 | 系统在做什么 |
|------|------|------------|------------|
| 起手 | 1-3 | "这游戏挺轻松" | 密度低，让玩家完成前 3 次选择 |
| 成形 | 4-8 | "我的 build 有点样子了" | 引入新敌人，开始有压力 |
| 高压 | 9-15 | "有点顶不住了" | 密度陡增，这段是手动接管的主战场 |
| 清算 | 16-19 | "满屏都是我的特效" | 密度最高，Build 全部兑现 |
| Boss | 20 | "终于打完了" | 单体高压收尾 |

**关键**：这条曲线必须是"先松后紧再爆"。中段（波 9-15）最容易掉人，
但这一段也应该是**手动接管最被需要的时段**——两条曲线叠在一起，才有"我救回来了"的时刻。

---

## 四、自动系统清单（默认状态）

| 系统 | 规则 | 玩家的间接影响方式 |
|------|------|-----------------|
| 自动瞄准 | 锁定最近敌人（**手动接管时让位**） | 通过卡改变优先级；或直接手指指定 |
| 自动开火 | 有目标即射，无目标停火 | 通过卡改变射速/弹数/弹道 |
| 自动换弹 | 弹夹打空后自动装填，装填期间无法开火 | 通过卡/武器提升弹夹容量与装填速度 |
| 自动道具 | 携带 2 个道具，冷却结束自动释放 | 通过卡缩短冷却或增强效果 |
| 升级 | 经验满自动弹卡 | 选什么 |

**这套设计的代价要说清楚**：换弹和道具的"无力感"是真实存在的。
补偿方式是把它变成 **Build 问题**而不是操作问题：这局被换弹卡死了，下局就该带大弹夹的武器。
**"问题在局内暴露，答案在选卡里"** ——这是这类游戏唯一能让玩家感到"我在玩"的方式。

## 五、手动接管

### 5.1 先解决一个陷阱：如果手动没有独占收益，玩家会学会"别碰"

自动瞄准锁最近目标，100% 命中，不疲劳，不挡屏幕。
手动瞄准：要点、要拖、手指挡画面、会累。

> **如果手动只是"把自动做的事手动做一遍"，最优策略就是全程不碰。**
> 这个功能会变成一个玩家不知道存在、做了也白做的系统。

这是这个提案唯一致命的地方。必须在规则层给手动一个**自动永远做不到的事**。

### 5.2 解法：手动的独占价值 = 越过前排，点杀后排

自动锁"最近"。自爆兵冲上来之前，远程兵在后面输出、治疗兵在奶——自动永远不会打它们。
**手动让你能穿过尸群，直接点后排。**

| | 自动瞄准 | 手动接管 |
|---|---|---|
| 目标选择 | 最近的前排目标 | **任意指定目标**（含后排、含空中） |
| 命中率 | 100% | 100%（**不考验精度和手速**） |
| 持续成本 | 0 | 手指离开后约 2.5 秒回归托管 |
| 换弹期间 | 停火 | **同样停火，不可绕过** |
| 本质 | 稳定输出 | **纠正错误目标**——一个专用工具 |

**这条纪律必须写死**：

> 手动瞄准只能解决「**打错人**」，不能解决「**打得不够狠**」。
> DPS 不够就是不够，手动救不了。

一旦手动能提升总输出，它就会从"工具"变成"必须一直做的事"，
而连续戳 6 分钟屏幕——那就不是你要的那个游戏了。

### 5.3 接管规则

| 项 | 规则 | 为什么 |
|----|------|--------|
| 触发 | 手指按下 / 拖动即接管 | 不设按钮，手指落在哪就打哪，直觉最优 |
| 回落 | 手指离开后维持 **2.5 秒**，然后回归自动 | 太短（1 秒）会碎成一地；太长（>5 秒）玩家会忘记自己在手动模式而漏怪 |
| 多点触控 | **只认第一个触点**，其余忽略 | 多点会让状态机混乱，且没有收益 |
| 换弹期间 | 点击不打断换弹；缓存最后一次输入，换弹结束后 0.2 秒内生效 | 避免"点了没反应"的挫败 |
| Boss 波 | **不强制锁 Boss** | 既然能手动锁，系统就不该再替玩家做这个决定 |
| 视觉反馈 | 接管期间准星与弹道转为高亮色 + HUD 显示一个回落倒计时环 | **没有视觉表达的功能等于不存在** |

### 5.4 手机上必须处理的问题：手指挡目标

玩家要点的目标就在他手指底下。三条缓解：

1. **准星画在触点上方约 40px**，手指本体不压住准星
2. **按下的位置不必压在敌人身上**——屏幕任意位置按下并拖动，指向按"枪口 → 触点"的连线角度计算
3. 接管期间被锁定的目标加**高亮描边**，手指挡住也知道在打谁

> 第 2 条最关键：**用方向角而不是精确点选**。玩家可以在屏幕空白处操作，完全不挡视野。

### 5.5 它对其他系统的连带影响

| 受影响的系统 | 变化 |
|---|---|
| 05 敌人设计 | **"必须先杀"类敌人可用**（治疗兵 / 远程兵 / 召唤师）。纪律：可做"必须先杀"，不做"漏杀一次就输" |
| 04 波次 | Boss 波不强制锁 Boss |
| 06 换弹 | 换弹不被手动接管绕过；换弹问题交给 Build（扩容 / 装填卡）解决 |
| 02/03 卡池 | 「战术目镜」（改变瞄准优先级）定位为**省力**，不是必需。它解决的是"我不想每次都手动点" |

## 六、三选一（主要输入）

| 项 | 规则 |
|----|------|
| 触发 | 局内等级提升时（一局约 20 次） |
| 形式 | 3 张卡，暂停游戏，选 1 张 |
| 卡池 | **三族**：武器卡（不占槽）+ 技能卡（占槽）+ 加成卡（定额，见 08 册） |
| 刷新 | 每局 1 次免费刷新（**不做广告**，改为通关/成就发放刷新券） |
| 放弃 | 不允许跳过（跳过等于白送一次升级，会破坏节奏） |

**为什么不能跳过**：这个游戏的乐趣在"决定"，允许跳过会让玩家用"随便点点"过关，然后觉得游戏很浅。

---

## 七、失败与胜负

| 项 | 规则 |
|----|------|
| 失败 | 要塞血量归零，立即结算 |
| 胜利 | 打完第 20 波（含 Boss） |
| 失败补偿 | 按到达波次给部分奖励（否则 6 分钟打水漂，会劝退） |
| 中途退出 | 保留波次快照，下次可续（手机上 6 分钟必然被打断） |

**不做的事**：体力限制、失败扣资产、看广告复活、抽卡开箱。
没有商业化诉求，这些东西只会碍事。

---

## 八、反馈通道

必须靠反馈维持注意力，四条通道缺一不可：

| 通道 | 要求 |
|------|------|
| 视觉 | 每个技能一个独占主色（温压弹橙红 / 干冰弹冰蓝 / 电磁穿刺紫电 / 高能射线青蓝 / 装甲车军绿 / 哨戒机钢灰 / 燃烧地带暗红 / 旋转刀轮银白）；击杀有碎块飞散 |
| 数字 | 伤害数字必须大、必须跳动、必须能看出"这一枪比上一枪狠" |
| 音频 | 射击音随武器等级变化（等级越高越沉）；弹种各有音色；升级音上扬；接管时有轻微音效区别 |
| 节奏 | 每次升级前 1-2 秒给一个"经验条将满"的微提示，让玩家有准备 |

**缺失任何一条，游戏会变成"挂机模拟器"。**

---

## 九、这一册定下的硬约束

1. 手动接管是**工具不是考核**：不要求精度、不要求频率、不存在"手残"。
2. 手动**只能纠正目标，不能提升输出**（这是防止它吃掉"决定"这个核心的防火墙）。
3. 挑战只能来自"选错卡"，所以**卡与卡之间必须有明显强弱差**，不能全是 +10% 的小数。
4. 6-7 分钟一局 + 20 次选择 = **平均每 20 秒打断一次**。弹卡必须快（动画 < 0.5 秒）。
5. 自动换弹 = 每 15-20 秒一次输出断档。这个断档是节奏呼吸，**不要试图消灭它**。
6. 撒手就应该能玩下去。任何时候玩家把手拿开，游戏都必须是**完整可通关的**——
   这是验收标准：**「全程不碰屏幕」必须能通过第 10 关**。
