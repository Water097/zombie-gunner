# 05 · 敌人设计

> 本册定义：有哪些敌人、它们考什么、在自动瞄准下敌人设计有哪些不能碰的红线。

---

## 一、先定一条红线

以前（玩家手动瞄准时）敌人设计的核心是"该先打谁"。
后来改成自动瞄准，这条逻辑作废，新的核心问题变成：

> **这个敌人会让玩家的 Build 在哪里漏风？**

敌人不是"需要被优先瞄准的目标"，而是"检验 Build 短板的考题"。

### 红线（半自动瞄准下的版本）

纯自动瞄准时，红线是"禁止做必须先杀的敌人"。现在有了手动接管，**这条解除**。

> **可以做"必须先杀"的敌人，但不做"漏杀一次就输"的敌人。**
> 它的代价应该是"多撑 15 秒很难受"，不是"瞬间团灭"。

治疗兵 / 召唤师 / 光环兵这类"必须先杀"的敌人**可用**——它们是手动接管存在的理由。
但不能做成"不点就必死"，否则变成操作考核，违反 P5（随手可撒手）。

**"必须优先处理"的效果仍然优先做成卡**（如"战术目镜：优先攻击自爆单位"），
它解决的是"我不想每次都手动点"，是省力，不是必需。

## 二、八种基础敌人

| 敌人 | 形态 | 行为 | 考什么 | 弱点 |
|------|------|------|--------|------|
| **普通兵** | 中等体型，灰绿，歪歪扭扭地走 | 直线推进 | 基线输出 | 无 |
| **疾行兵** | 瘦小、驼背、跑得很快 | 高速直线冲线 | 爆发力（来不及打就过去了） | 血薄 |
| **自爆兵** | 圆胖、肚子发红光、越走越鼓 | 冲到防线前自爆，造成大额伤害 | 防线厚度 / 单体爆发 | 血薄但伤害高 |
| **远程兵** | 高瘦、长手、站在后排 | 停在半场，持续向防线喷吐 | 续航（它不会冲，但一直削血） | 血薄，但打不到就没辙 |
| **装甲兵** | 厚重、带铁皮、走得慢 | 直线推进，普通子弹减伤 | 穿透 / 破甲 / 元素伤害 | 移速慢 |
| **飞行兵** | 悬浮、有翼、贴地飞 | 无视地面单位，直线飞向防线 | 覆盖面（需要弹道覆盖空中） | 血薄 |
| **分裂兵** | 鼓胀、半透明、体内有东西 | 死亡时分裂成两只小兵 | 清群能力 / AOE | 单体很弱 |
| **蜂群** ⭐ | 极小、成片、横向铺开 | 出生即散成一排，间距大，快速推进 | **覆盖率**（AOE 打不全、穿透打不穿） | 血量极低，但**数量就是它的血条** |

### ⭐ 二·五、技能 ↔ 敌人覆盖率表

**这张表回答一个问题：9 个技能里，有哪个是"没有任何敌人能难住它"的？**
如果有，说明它不是强，是**没被考过**——那它的强度就是假的。

#### 填表

| 技能 | 正面强项 | **需要的反面考题** | 现有敌人能考吗 |
|------|---------|------------------|--------------|
| 温压弹 | 清群（**密集**） | 分散的敌人，AOE 打不全 | ✅ **蜂群**（二·六） |
| 干冰弹 | 拖延（减速） | 高速冲刺／减速抗性 | ✅ 疾行兵（窗口短）＋ **装甲兵减速抗性 ×50%**（二·七） |
| 电磁穿刺 | 打队列（穿透） | 散开，穿透打不穿 | ✅ **蜂群**（二·六） |
| 高能射线 | 持续单体 | 数量暴涨，一次打不完 | ✅ 分裂兵（＋蜂群：一次一个被淹没） |
| 装甲车 | 击退·守线 | 免疫击退 | ✅ **装甲兵抗击退 ×25%**（二·七） |
| 哨戒机 | 覆盖·兜底 | 绕过它的路径 | ✅ **飞行兵只有后 30% 路程进射界**（二·七） |
| 燃烧地带 | 封锁地面 | 快速通过／飞行无视 | ✅ 疾行兵、飞行兵 |
| 旋转刀轮 | 横向清越线 | 空中单位够不到 | ✅ 飞行兵 |
| 制导激光 | 窄扇面清线 + 聚焦清要点 | 散开仍偏窄（但 10 级扇面 +200% 缓解） | ⚠️ **蜂群**仍偏难受（二·六，程度已减轻）＋ 分裂兵 |

#### 统计（2026-10-30 更新：三条属性已写死；末补入制导激光，9/9 全覆盖）

```
有明确反面考题：  9 个  ← 全覆盖，表中不再有 ⚠️
其中补入蜂群解决的：3 个  （温压弹 / 电磁穿刺 / 制导激光*）  *制导激光现为窄扇面扫射，蜂群仍偏窄、弱点已减轻
其中靠写死敌人属性解决的：3 个  （干冰弹 / 装甲车 / 哨戒机）
其余本来就有清晰反面考题：3 个  （高能射线 / 燃烧地带 / 旋转刀轮）
```

#### 结论：缺一个敌人，而且只需要加一个

温压弹、电磁穿刺缺的是**同一个东西**——**"散开"的敌人**（制导激光原是单体锁定同样被克；现改为窄扇面扫射，10 级前仍偏窄、蜂群铺太开难全扫，弱点已减轻）。
所以不用加两种，加一种就够。

### ⭐ 二·六、第 8 种敌人：蜂群

> 它是敌表里**正式的第 8 号**。04 册波次表、本册第六节波次绑定、视觉规范都已按它存在来写。

| 项 | 设计 |
|----|------|
| **形态** | 极小（约普通兵 1/3）、**成片出现**、横向铺开、间距明显 |
| **行为** | 出生瞬间就散成一排，**不聚堆**，快速直线推进 |
| **血量** | 极低（普通兵的约 15%）——**数量就是它的血条** |
| **考什么** | 温压弹（散开 → 爆炸覆盖不全）<br>电磁穿刺（散开 → 穿透一次只过 1 个）<br>高能射线（一次一个 → 被淹没）<br>干冰弹（减速的单位价值被稀释） |
| **被谁克制** | 燃烧地带（横向面积正好封住）<br>旋转刀轮（横向扫荡，正对散开队形）<br>哨戒机（自动分散打击） |
| **剪影 / 颜色** | 极小成片 / **暗黄** |

#### 为什么这个敌人值

**它能把 9 个技能劈成两半。**

| 遇到蜂群波时 | |
|---|---|
| **难受** | 温压弹 / 电磁穿刺 / 高能射线 / 干冰弹（4 个） |
| **舒服** | 燃烧地带 / 旋转刀轮 / 哨戒机（3 个） |
| **中立** | 装甲车（击退对蜂群仍有效，但推不完）／ 制导激光（窄扇面偏弱，10 级后缓解） |

玩家遇到蜂群波的那一瞬间，会立刻知道自己这局 Build 偏哪边——
**这就是"考卷"该有的样子**：不是"这个敌人很难"，是"这个敌人能测出你是什么流派"。

#### 三条硬约束（不加就会玩坏）

| # | 约束 | 理由 |
|---|------|------|
| 1 | **蜂群只在特定波出现**（建议波 7 / 13 / 17），不做常态 | 它是"检查点"，不是日常。每次都来会让 4 个技能变成废卡 |
| 2 | **单次出生量要有上限**（建议 8-12 只） | 数量就是它的血条，无上限会瞬间淹没防线，且无法配平 |
| 3 | **蜂群不触发"手动接管"的价值** | 手动只改目标不改输出。面对蜂群，点哪个都一样——**这是有意的**，它就是纯 Build 检验 |

#### 一个连带收益：它让换弹变危险

弹夹 30 发，蜂群一次来 10 只。
**如果换弹的 1-2 秒撞上蜂群波，防线会肉眼可见地被撕开。**
这正好强化 06 册那条"换弹期间 DPS 归零"的紧张感——
原本这个紧张感只在尸墙波才明显，现在多了一个更清晰的触发点。

#### ⚠️ 但它有一个坑

蜂群血量极低 → **任何"溅射/连锁"类效果在它面前都会超神**（温压弹的连锁引爆、燃烧地带的蔓延）。
这会让"温压弹在蜂群波里又变强了"，与"蜂群克温压弹"的设计意图打架。

**解法**：蜂群**死亡时不产生尸体爆炸**（温压弹连锁引爆的燃料没了）。
一句话就能把这条反向关系锁死，且符合直觉（它太小了，炸不起来）。

### ⭐ 二·七、三条写死的敌人属性（覆盖率表 9/9 的最后一块）

覆盖率表里那 3 个 ⚠️ 之所以是 ⚠️，是因为它们挂在"某条敌人属性"上，**而那条属性从来没被写过**。
不写死，干冰弹 / 装甲车 / 哨戒机三个技能的强度就是**没被真正考过的**——
看着有考题，实际上考题的答案是空的。

**这三条的共同原则：抗性是"打折"，不是"作废"。**
完全免疫会让对应技能变废卡，而我们要的是"它还能用，但不够了"。

---

#### ① 装甲兵 · 抗击退（考装甲车）

```
受到的击退位移 = 常规 × 25%
免疫  ：所有「击飞 / 弹开 / 强制位移」类特效
不免疫：位移以外的控制（减速 / 眩晕 / 冻结）与一切伤害
其他  ：精英怪 ×40%，Boss ×10%（Boss 按 04 册"不免疫控制"，只给极低倍率）
```

**为什么是 25% 而不是 0%**：
- 0% = 装甲车对装甲兵彻底成废卡，玩家会感到"这局白点了"
- 25% = **推得动，但推不回去**。玩家看得见它在被推，同时立刻明白"推是推不动的，得换手段"
- 装甲兵本来就走得慢，25% 击退落在它身上几乎不改变到达时间 → 这个抗性**与它的"慢"是互补的，不是重复的**

**玩家的正确答案**（必须是另一条路，不是"再多推几次"）：
穿透 / 破甲 / 元素伤害，或者用燃烧地带 + 哨戒机在它到线之前把它磨掉。

---

#### ② 装甲兵 · 减速抗性（考干冰弹）

```
受到的减速幅度 = 常规 × 50%
持续时间        = 不打折（常规 × 100%）
```

**砍幅度、不砍时间**。理由：
- **砍幅度** → 玩家仍看得见"它慢下来了"，视觉反馈还在（对辅助线来说，反馈就是价值）
- **不砍时间** → 干冰弹的"状态③投法"（持续 +2 秒）不被这一条打废，它还是半条有用的辅助线
- 结果：一发干冰弹对装甲兵 = 半速前进 4 秒。**有用，但"靠减速把装甲兵钉死"不成立**

⚠️ **调节旋钮（留给数值阶段）**：如果 playtest 发现干冰弹对装甲兵仍太强，
再把**持续时间**也砍一半（总收益 ×25%）。**先砍一刀，别一次砍两刀。**

**顺带写死疾行兵：减速抗性 = 0%。**
它的考法来自**移速基数大**（减速后绝对位移仍然大），不是来自抗性。
两条敌人的考法必须不同——否则"减速抗性"会变成一根通用拐杖，谁都能拿来用。

---

#### ③ 飞行兵 · 路径真的绕过哨戒机（考哨戒机）

```
哨戒机射界 = 以自身为圆心、半径 R 的圆 + 仰角上限 35°
飞行兵     = 高空巡航（在 35° 线以上）→ 最后 30% 路程俯冲 → 俯冲段才落进射界
→ 哨戒机对飞行兵的有效窗口 = 全程的后 30%
```

**为什么不是"完全打不到"**：
- 完全打不到 = 哨戒机在飞行兵面前是废卡，玩家会觉得被坑
- 而 30% 窗口正好落在**最接近防线那一段** → 在最危险的时刻它仍然管用，
  **保住了"兜底"这个人设**，只是兜底覆盖率从 100% 掉到 30%

**三条连带规定**：

| # | 规定 | 理由 |
|---|------|------|
| 1 | 飞行兵**不免疫击退 / 减速** | 它的抗性来自**路径**，不来自属性。三种敌人用三种机制来"抗"，不要都堆成属性免疫——否则玩家记不住 |
| 2 | 哨戒机的**部署位置玩家可调**：后场 = 只有俯冲段；前场 = 能多打一会儿但容易被拆 | 把 30% 变成**可争取的**，给玩家留一条解法，而不是让他只能认命 |
| 3 | **第 1 章不给哨戒机「防空瞄具」卡**（提升仰角） | 一旦给了，哨戒机对空覆盖满 → 覆盖率表白填，它又变成万能兜底 |

---

#### 三条落定后的净收益

```
改动前（早期 8 技能、未计制导激光）：8 个技能里 3 个的"强度"是没有被考过的（表上 3 个 ⚠️）
改动后：9/9 全覆盖，且三个技能各自知道了自己"不够用"的具体场景

装甲车 → 遇到装甲兵：能推，推不回去
干冰弹 → 遇到装甲兵：能拖，拖不死
哨戒机 → 遇到飞行兵：能打，只打得到最后一段
```

**这三个"能，但不够"就是设计要的东西**：不是让技能失效，是让技能**显出边界**。

---

### 为什么是这八种

每一种对应一个 Build 维度，八个就是一整套"体检表"：

```
输出不足      → 疾行兵漏过去
爆发不足      → 自爆兵炸到防线
爆发不足      → 疾行兵冲过去了
续航不足      → 远程兵慢慢磨死你
穿透不足      → 装甲兵堆成墙
覆盖不足      → 飞行兵从头顶飞过
清群不足      → 分裂兵越打越多
**覆盖广度不足 → 蜂群散开，AOE 打不全**
整体不够      → 普通兵数量压死你
```

玩家一局下来，能清楚知道自己"死在哪一项"——这就是零操作游戏里唯一能提供的"复盘感"。

## 三、精英怪与 Boss

### 先区分两个经常被混用的词

| 词 | 出现位置 | 是什么 |
|----|---------|-------|
| **精英怪** | 每关的**波 5 / 10 / 15** | 体型大、血厚、走得慢、周期召唤杂兵。它是"压力峰"，**不是 Boss** |
| **Boss** | 每章的**第 5 关、第 10 关**的**第 20 波** | 一章只出现两次，有专属机制与阶段行为 |

**命名统一：第 20 波只有两种形态——Boss 关出 Boss，其余关是最厚尸墙。**
"精英怪"只指波 5/10/15 那种血厚走得慢的，不叫"小 Boss"。

### 精英怪

体型约为普通兵 3 倍，血厚，**走得慢**，会周期性召唤杂兵。

**精英怪的纪律：它必须"慢"。**
慢才能让玩家有时间把火力倾泻在它身上；如果它跑得快，它就变成一个"血厚的疾行兵"，
玩家只会觉得烦躁，而不是觉得难。

### Boss 的四条硬约束

这个游戏的技能是**独立攻击体系**（装甲车、射线、刀轮），价值都在"面"上。
一个只考单体爆发的 Boss，会让铺面 Build 在最后一分钟突然失效——那不是难度，是背叛。
**所以 Boss 不能用"血极厚"来定义。**

四条硬约束（详见 04 册第五节）：

| # | 约束 |
|---|------|
| 1 | 必须**持续召唤杂兵**，构成随阶段变化 |
| 2 | **散布在空间**：多部位可分别破坏，或分阶段多个出场 |
| 3 | **血量不能高到打不动**——难点是资源分配，不是血条长度 |
| 4 | **不免疫任何控制** |

**所以 Boss 的正确答案不是"爆发"，是"一边维持清场，一边抽出资源打掉高价值目标"。**

### 每个 Boss 绑定一条专属机制

一章两个 Boss × 后续章节，每章都要有新东西。换皮立刻会被看穿。
建议每个 Boss 绑定一条独占机制：**召唤 / 护盾 / 分裂 / 地形改变 / 增益光环 / debuff 反弹**。

## 四、视觉与可读性

自动瞄准下，玩家没时间细看，所以敌人必须**在 0.2 秒内被认出来**：

| 维度 | 规则 |
|------|------|
| 轮廓 | **八种**敌人的剪影必须互不相似（胖/瘦/高/矮/悬浮/带甲/鼓胀/**极小成片**） |
| 颜色 | 普通灰绿、疾行暗红、自爆橙红发光、远程紫灰、装甲铁青、飞行浅蓝、分裂黄绿、**蜂群暗黄** |
| 体积 | 血越厚越大（玩家的直觉：大的难打） |
| 危险信号 | 自爆兵靠近时肚子红光脉冲加速；远程兵抬手时有蓄力前摇 |

**最关键的一条**：自爆兵的"要炸了"必须能被余光捕捉到。它是唯一一个"来不及就掉一大块血"的敌人，
如果玩家事后才反应过来，会觉得是游戏在偷袭。

## 五、台词系统（低成本高回报）

参考视频里最聪明的一处细节：僵尸头顶会冒气泡说话——
「懵懵我啊又来了了了」「好像长脑子了…」「这把我硬起来了…」。

砍第 200 只和第 1 只僵尸在机制上完全一样，但一句台词就能让玩家笑一下。
这是性价比最高的个性来源，而且几乎不占开发成本。

### 规则

| 项 | 规则 |
|----|------|
| 内容 | 自嘲、荒诞、生活化、和"当僵尸"这件事有关。不要玩梗过时，不要网络流行语 |
| 每人 | 每种敌人 4-6 句，随机抽 |
| 触发 | 出生时 / 接近防线时 / 被击杀时 三选一 |
| 频率 | **同屏最多 3 个气泡**，同一只敌人 10 秒内只说话一次 |
| 语气 | 憨、丧、有点小骄傲。不要凶，不要脏话 |
| **长度** | **硬上限 12 字**。理由不是文艺：气泡在手机上换行超过两行就会盖住战场 |

### ⚠️ 首版范围：只做 3 种

全量是 8 种 × 8-12 句，而且每句还要配**触发条件**（出现 / 受击 / 死亡 / 被冻结 / 被击退）。
这不是"写 40 句话"，是**写 40 句话 + 40 条触发规则 + 一套气泡 UI**。首版全做会拖慢上线。

**首版只给 3 种高频敌人写台词：普通兵 / 自爆兵 / 精英怪。**
这三种出场次数占 80% 以上，性价比最高。其余等主体跑通之后再补。

| 敌人 | 首版句数 | 优先级 |
|------|---------|--------|
| **普通兵** | 10-12 句 | P0（出场最多，最容易重复） |
| **自爆兵** | 6-8 句 | P0（威胁感强，反差笑点最好写） |
| **精英怪** | 6-8 句 | P0（体型大，气泡不会被挡） |
| 疾行兵 / 远程兵 / 装甲兵 / 飞行兵 / 分裂兵 | — | **延后** |

**样本**（按敌人分）：

- 普通兵：「又是我」「这次一定行」「腿有点软」
- 疾行兵：「让让让让」「我最快」「跑起来就不怕了」
- 自爆兵：「我有点胀」「别靠太近」「三、二…算了」
- 远程兵：「我在这儿就行」「你们先上」「慢慢来」
- 装甲兵：「打不动的」「这身挺沉」「铁皮真好」
- 飞行兵：「上面风大」「你们在下面挤什么」
- 分裂兵：「我肚子里有东西」「要分家了」

## 六、敌人与波次的绑定

| 波次段 | 出场敌人 |
|--------|---------|
| 1-3 | 普通兵为主，3 波引入疾行兵 |
| 4-8 | 加入自爆兵；**7 波首次出现蜂群**（检查点）；8 波为喘息波（只出普通兵，密度低） |
| 9-15 | 加入远程兵、装甲兵、飞行兵；**13 波蜂群**；14 波喘息 |
| 16-19 | 全类型混编，密度最高；**17 波蜂群**（最后一次检查点） |
| 20 | 尸墙（第 5/10 关为 Boss + 杂兵） |

**蜂群的三次出场是刻意排的**：波 7（刚学会 2 个技能时）、波 13（Build 半成型）、波 17（快成型）。
每次它问的都是同一个问题——**"你这套 Build 有多宽？"**——
而三次答案会不一样，玩家能感觉到自己是怎么从"被蜂群撕开"到"一刀切过去"的。

每种新敌人只在**一个"引入波"**里单独登场，之后才混编。一次塞两种新敌人，玩家分辨不出来，也学不会。
