# 15 · 关卡奖励与兑换机制

> 本册定义：一关打完给什么、怎么发、碎片怎么流转、能兑换什么。
> 前提：本册**只管"关卡产出与兑换"这一层**；具体数值（碎片数量、金币、经验阈值、衰减斜率）标注 ⚠️ 的为**临时基准**，等机器模拟游戏时再校准。
> 强约束（继承 **07 §六**）：**不做扭蛋、不做抽卡、不看广告、不做体力**。兑换界面只服务"武器碎片 → 武器解锁"这一件事。
> 2026-10-30 拍板结论已并入本册：评级系统自建；兑换仅武器（兑换数 ≤100）；通关送技能碎片 + 金币（用于升技能等级）；首通最大；重复通关随战力衰减；失败按表现给奖；回血不在此册（见 03/07）。

---

## 〇、货币总览：四种局外货币，各管一摊，无死资源

| 货币 | 来源 | 用途（唯一去向） | 是否随战力衰减 |
|---|---|---|---|
| **局外经验 Exp** | 每关通关固定 | → 局外等级（账号级，解锁卡池节奏，见 03 §六） | ✅ 衰减 |
| **金币 Gold** | 每关通关固定 | → 技能等级升级的**基础花费**（软货币） | ✅ 衰减 |
| **技能碎片 Shard** | 每关通关固定（少量） | → 技能等级升级的**硬性门槛**（每级额外需 N 个） | ✅ 衰减 |
| **武器碎片 Fragment**（按武器分种类） | 特定关掉特定武器碎片；Boss/精英掉**独占武器**碎片 | → 集齐兑换解锁该武器（≤100） | ❌ 不衰减（解锁型） |

**为什么分四种不合并**：
- 局外经验 = 账号级进度（决定你能不能用高级卡），和"单技能变强"是两回事，不能合并。
- 金币 = 软货币（刷就有），技能碎片 = 硬门槛（防纯金币无限堆满），两者合起来才构成"技能升级"的真实成本——只给金币会被无限刷爆，只给碎片又太肝，配对最稳。
- 武器碎片 = 解锁型（集齐即用），它**不衰减**：解锁靠"打过 + 集齐"，不能因为你变强就少给，否则满级玩家反而解锁不了新武器。

> 四种货币都有明确去处，没有"打出来没用"的垃圾掉落。

## 一、每关通关奖励结构

一次通关的产出 = **基础产出（必给）** × **评级倍率** ＋ **首通奖励（仅首次）**。

### 1.1 基础产出（任一评级都给，⚠️ 临时基准）

| 产出 | 普通关 | Boss 关（5/10） | 精英难度 |
|---|---|---|---|
| 局外经验 | 40 | 100 | ×1.8 |
| 金币 | 50 | 120 | ×1.8 |
| 技能碎片 | 3 | 8 | ×1.8 |
| 该关对应**武器碎片** | 6 | 12（Boss 独占武器） | ×1.5 |
| 装备 ×1（随机部位/品级，见 07 §4） | ✓ | ✓（品级上浮） | ✓（品级上浮更高） |

- 装备同部位同存档只掉一次（07 §4.5），旧装备自动分解为通用碎片（见第四节）。
- 武器碎片按关指定：不同关掉不同武器（06 §六 / 07 §五）；Boss 关掉的是"只有该 Boss 才掉的独占武器碎片"。

### 1.2 评级系统（自建，只看"打得多漂亮"）

评级只看战斗结算的两个维度，**通关才评级，失败走第五节**：

| 评级 | 触发条件（全部满足） | 奖励倍率（乘在基础产出上） |
|---|---|---|
| **S** | 要塞剩余血量 ≥ 80% 且 用时 ≤ 基准 ×0.8 且 **未触发要塞急救卡** | ×1.5 |
| **A** | 剩余血量 ≥ 50% 且 用时 ≤ 基准 | ×1.2 |
| **B** | 通关即可，但剩余血量 ≥ 20% 或 用时 ≤ 基准 ×1.3 | ×1.0 |
| **C** | 通关但剩余血量 < 20% 或 超时 | ×0.8 |

- **评级只调倍率，绝不剥夺基础产出**——C 也照样给装备/碎片/金币，只是少一点。零操作游戏该有的善意。
- "基准时长" = 该关设计预期通关时间，写进 **04 册关卡配置**（数值阶段定）。
- "未触发急救卡"作为 S 的附加条件，是为了奖励"硬实力碾压"而非"靠急救卡苟活"。

### 1.3 首通奖励（仅首次，单关收益峰值）

首次通关某关（任意难度）额外给：

| 产出 | 数量（⚠️ 临时基准） | 说明 |
|---|---|---|
| 武器碎片 | +20 | 相当于白送约 3 次重复量，鼓励推进度 |
| 金币 | +100 | — |
| 技能碎片 | +10 | — |
| 局外经验 | +60 | — |
| 解锁该关**精英难度**（若有） | — | 主线推进钥匙 |
| 成就点 | 1 | 占位，后续成就系统 |

> 首通是单关收益最高点，**设计意图是逼玩家向前推图，而不是反复刷同一关刷满**。

## 二、重复通关的战力衰减算法（我定）

**问题**：玩家变强后回头刷低级关，若不衰减，低级关产出和高级关一样，经济崩塌、低级关变成最优刷点。
**解法**：重复通关的**软货币产出（经验/金币/技能碎片）** × 战力衰减系数；武器碎片（解锁型）不受影响。

### 2.1 玩家战力 P（算法）

```
P = 装备分 + 等级分 + 技能分 + 武器分

装备分  = Σ(各部位品级基础分)
          品级基础分：白 10 / 蓝 20 / 紫 35 / 粉 55 / 金 80 / 灾厄 110
          （6 部位全灾厄 ≈ 660）

等级分  = 局外等级 × 5
          （假设满级约 60 → 300）

技能分  = Σ(9 个技能各自等级) × 2
          （9 技能满 20 级 → 360）

武器分  = 已解锁武器数 × 15
          （假设 12 把武器 → 180）

P 为原始分，仅用于和关卡推荐战力 R 比较，不直接当伤害。
```

### 2.2 关卡推荐战力 R

每个关卡在 **04 册配置**里写 R（设计预期"刚好能过"的战力）。示例（⚠️ 临时基准）：
`R1=80，R3=180，R5(Boss)=350，R8=550，R10(Boss)=800`。

### 2.3 衰减系数

```
m = clamp( R / max(P, R) , 0.20 , 1.0 )

- P ≤ R（你偏弱或刚好）：m = 1.0（满额，鼓励越级挑战）
- P = 2R（碾压）：    m = 0.5
- P ≥ 5R（完全碾压）：m = 0.20（地板，防刷）
```

**效果**：你比这关强越多，刷它越不划算，逼你去推更高级 / 精英 / Boss。武器碎片不乘 m（解锁逻辑独立）。

## 三、兑换机制（只做武器）

| 动作 | 规则 | 是否做 |
|---|---|---|
| **武器解锁** | 某武器碎片集齐 → 永久解锁该武器（唯一兑换动作） | ✅ 做 |
| 装备合成 / 兑换 | 装备只靠关卡随机掉落，无合成 / 兑换界面 | ❌ 不做（07 §4 已定） |
| 扭蛋 / 抽卡 | — | ❌ **不做**（07 §六 硬约束） |
| 看广告 / 体力 | — | ❌ 不做 |

### 3.1 兑换所需碎片数（我定，均 ≤100，⚠️ 临时基准）

| 武器类型 | 所需碎片 | 大致通关次数（含首通 +20） |
|---|---|---|
| 普通武器（白/蓝/紫） | **60** | 普通关约 7~8 次（6/次，首通 +20） |
| 粉 / 金武器 | **80** | 约 10 次 |
| **Boss 独占武器** | **100** | 仅 Boss 关掉（12/次），约 7~8 次 Boss |

### 3.2 溢出闭环

- 已解锁武器的碎片若继续获得 → 自动转 **通用碎片**（1:1），喂给其他未解锁武器的缺口（防止死资源，与 07 一致）。
- 兑换界面只做一件事：展示各武器碎片进度，集齐即解锁。不做任何"花碎片赌一把"的设计。

## 四、碎片经济闭环

```
武器碎片（按关指定 / Boss 独占）
   ├─ 集齐 → 永久解锁该武器（06 / 07 已定）
   └─ 已解锁武器的碎片 → 自动转为【通用碎片】

通用碎片 ← 武器碎片溢出 + 装备分解 + 高评级奖励
   └─ 用途：喂给其他未解锁武器的碎片缺口（唯一去向）

装备分解：同部位只穿 1 件，旧装备自动分解为通用碎片（07 §4.5）
   └─ 防止仓库膨胀，给"换装备"正反馈（不是扔掉，是喂给武器解锁）
```

**闭环目的**：没有任何奖励是"死"的。重复关的溢出碎片、换下的旧装备，都流回"解锁下一把武器"这个目标。

## 五、失败奖励（看表现，不归零）

失败也发奖，按"这局打得多认真"给，避免挫败感彻底归零；但**失败不掉武器碎片、不掉装备**（防用失败刷解锁）。

**表现指标**（取三者最高覆盖，clamp 到 0.3~0.8）：

| 指标 | 计算 |
|---|---|
| 波次进度% | 已清波数 / 总波数 |
| Boss 伤害% | 对 Boss 造成总伤害 / Boss 最大血量（非 Boss 关取 0） |
| 存活时间% | 实际存活时间 / 预期通关时间 |

**失败产出**（⚠️ 临时基准）：

| 产出 | 公式 | 保底 |
|---|---|---|
| 金币 | `max(15, round(50 × 0.5 × 表现系数))` | 至少 15 |
| 技能碎片 | `max(1, round(3 × 0.5 × 表现系数))` | 至少 1 |
| 局外经验 | `round(40 × 0.5 × 表现系数)` | 至少 5 |

例：打到第 8/10 波（80% 进度）团灭 → 表现系数 0.8 → 金币 `max(15, round(50×0.5×0.8)=20)=20`，技能碎片 `max(1, round(3×0.5×0.8)=1)=1`，经验 `round(40×0.5×0.8)=16`。
失败不掉武器碎片 / 装备，但给"安慰奖"，让团灭也有正向反馈、不劝退。

## 六、Boss / 精英独占物（大白话 + 决策）

**一句话**：让"最难的内容"掉"只有那里才掉的东西"，否则玩家会去刷最轻松的关。

三种候选形态（2026-10-30 讨论）：

| 形态 | 大白话 | 本期决策 |
|---|---|---|
| **专属碎片** | 某把武器只能在某个 Boss 掉它的碎片，别处一颗都没有——"必须去打这个 Boss"的硬锁 | ✅ **采用**为主独占物（契合"兑换只做武器"） |
| **材料** | 强化/升级用的材料。但本期没做装备强化/镶嵌（07 §六），造出来没处花 → 死资源 | ❌ **本期砍掉** |
| **外观** | 纯皮肤，枪换个样子不加战力，硬核通关的荣誉勋章 | ⚪ 可选荣誉奖励（不加数值，纯收集/炫耀） |

**落地**：Boss 关掉"boss 独占武器"的专属碎片（兑换数 100，见 §3.1）；精英难度在普通产出上 ×1.5~1.8 且不掉独占物（独占物仍是 Boss 专利），但给更多软货币 + 更高品级装备——这是"愿不愿意挑战更难"的理由。

## 七、技能升级的花费（金币 + 技能碎片的去向，摘要）

技能从 L 升到 L+1 的成本（⚠️ 临时基准，详细数值以 07 册局外养成为准）：

```
金币花费   = 40 × L
技能碎片   = 1 + floor(L / 4)
```

| 升级 | 金币 | 技能碎片 |
|---|---|---|
| 1 → 2 | 40 | 1 |
| 10 → 11 | 400 | 3 |
| 19 → 20 | 760 | 5 |

9 个技能满级总花费约为数万金币 + 数百技能碎片——靠"通关给金币/碎片 + 衰减"自然支撑，不会一夜堆满，也不会卡死。

## 八、与"要塞回血"的解耦（重要交叉说明）

**要塞回血不再作为关卡奖励、也不再绑定"每波清怪"。** 这是 2026-10-30 拍板取消的旧方向。
回血改为两条独立路径，且都**不依赖清波**：

1. **装备常驻回血词条**（07 §4.2.1 头肩）：`要塞生命回复 +X/s`，**数值随装备品级**（白 2 / 蓝 2.8 / 紫 3.6 / 粉 4.4 / 金 5.2 / 灾厄 6）。⚠️ 临时基准，待机器模拟校准。
2. **低血触发的要塞急救功能卡**（03 册第九节）：要塞血量首次跌破 50% 后，下一次升级抽卡 50% 概率发「要塞急救：回复 30% 最大血量」，一局仅一次。⚠️ 临时基准（50% / 30% / 50% 阈值均待校准）。

> 本册**不列出任何"回血"类奖励**。要塞续航来自"穿对装备"和"低血时的抉择"，不是"每波自动回血"（旧"精华提取"卡已删，见 08 册）。
