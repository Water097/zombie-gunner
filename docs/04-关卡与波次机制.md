# 04 · 关卡与波次机制

> 本册定义：20 波怎么编排、难度怎么递进、第 20 波怎么收尾、章节和关卡怎么组织。
> 核心规格：**20 波连续，波与波之间无停顿**。

---

## 一、单局规格

| 项 | 规则 |
|----|------|
| 波数 | 20 波 |
| 波间停顿 | **无**。上一波清空/超时后，下一波立即接上 |
| 单波时长 | 约 18-21 秒（第 20 波尸墙约 25-30 秒） |
| 单局时长 | 约 6-7 分钟 |
| 结束条件 | 打完第 20 波（胜利）或要塞血量归零（失败） |

**没有停顿怎么让玩家感知"换波了"**：靠四个信号同时切换——
① 顶部波次数字跳动 ② 敌人种类换一批 ③ 音乐层切换 ④ 屏幕边缘扫一道光。
**不用"倒计时暂停 + 大字提示"这种硬切**，那会打断本来连成一口气的战斗流。

---

## 二、战场空间与出怪区

### 规则

```
出怪区 = 屏幕【顶部一横条】，垂直范围从顶端到中线为止（绝不超过中线）
        横向全宽，内部划分为若干入口（左 / 中 / 右，或更多）
侧翼来的敌人也从这条带里出现，不从屏幕左右边缘走进来
```

这条规则带来的第一个好处是**给了"防线"一个物理定义**：

```
┌─────────────────┐ ← 屏幕顶：出怪带
│  ▓▓▓▓ 出怪区 ▓▓▓▓ │
├─ ── ── ── ── ── ┤ ← 中线 = 警戒线（可见）
│                 │
│      安全区      │
│                 │
│      ◆ 要塞      │ ← 底部
└─────────────────┘
```

**中线做成一条肉眼可见的警戒线**。敌人越过中线才真正造成威胁（伤害加深 / 加速推进）。
这让"守住中线"成为一个可感知的目标，也让录屏里装甲车的**击退**效果有了意义——
击退的价值不是伤害，是**把敌人推回警戒线以上**。这是零操作游戏里少数能被"看见"的控制效果。

### ⚠️ 但这条规则有两个连带后果必须补偿

**① 手动接管的"点杀后排"价值下降。**
原来假设后排远程兵可能藏在屏幕下半部，手动能越过前排点它。
现在所有敌人都挤在上半屏那一横条里，前排后排的**空间分离度变小**，
"越过前排点后排"的操作空间被压缩了。

补偿办法：让侧翼/远程单位的**行为**拉开差距，而不是靠位置。
例如远程兵会主动拉开距离停在出怪带的最上沿，而不会跟着尸潮往下走——
它的"远"体现在**移动逻辑**上，不是出生点上。

**② 入口变窄 = 实际密度上升。**
同样的刷怪量挤进原来一半的面积，单位面积密度翻倍。
按原先的密度参数跑，前几波就会显得比设计意图更挤。
→ 需要处理：**所有密度参数必须在"窄带"前提下重新校准**，
尤其要检查前 3 波（本来是教学波）会不会因为挤压而失去"看清发生了什么"的功能。

## 三、20 波的功能编排

每一波都要有一个"职能"，不能只是"比上一波多几只"。否则第 10 分钟玩家会觉得在重复。

| 波 | 职能 | 内容 | 设计意图 |
|----|------|------|---------|
| 1 | 起手 | 普通僵尸，单通道 | 让玩家看清"我的枪在打什么" |
| 2-3 | 热身 | 密度缓升，出现快速兵 | 完成前 2-3 次升级，Build 有雏形 |
| 4 | **引入** | 自爆兵（冲向防线自爆） | 第一次"防线会被突破"的实感 |
| 5 | **精英** | 双精英怪 + 杂兵 | 第一个压力峰（非 Boss 关仍是尸墙收尾） |
| 6-7 | 上升 | 密度爬坡，双通道；**7 波首次出现蜂群**（检查点） | 建立"越来越挤"的预期；第一次问"你的 Build 有多宽" |
| 8 | **喘息** | 密度骤降 + 掉落补给 | 让玩家松一口气，同时冲等级 |
| 9 | **引入** | 远程兵（停在出怪带最上沿输出） | 它不会冲过来，但会持续削血；也是手动接管的教学场景 |
| 10 | **精英** | 双精英怪 | 中段大考 |
| 11 | **引入** | 装甲兵（抗击退 ×25%、减速抗性，需要穿透/元素） | 惩罚"只会堆伤害"的 Build |
| 12-13 | 上升 | 13 波引入飞行单位；**13 波蜂群** | 攻击面从"一条线"变成"一片" |
| 14 | **喘息** | 密度骤降 + 补给 | 第二次呼吸 |
| 15 | **精英** | 双精英怪 + 装甲混合 | 终局前的最后一道坎 |
| 16-18 | **高压** | 三通道同时涌，全类型混编；**17 波蜂群**（最后一次检查点） | 满屏压力，Build 全部兑现 |
| 19 | **清算** | 全类型 + 高密度 | 纯粹的爽感释放 |
| 20 | **尸墙 / Boss** | 非 Boss 关：最高密度尸墙；第 5、10 关：Boss | 用"撑住"或"打掉它"收尾 |

**两条编排纪律**：
1. 每个"引入"波只放**一种**新敌人。一次塞两种，玩家分辨不出来。
2. 高压段（16-18）之前必须有喘息波（14）。没有喘息的高压只是疲劳。

## 四、波次的事件层（防重复）

20 波 × 多关，光靠编排表会很快被玩家看穿。所以加一层**随机事件**，每局抽 2-3 个：

| 事件 | 效果 | 出现位置 |
|------|------|---------|
| 空投补给 | 掉落一个随机增益（临时攻速/护盾/额外刷新） | 落在任意波 |
| 尸潮突变 | 某一波的敌人全部换成同一类型 | 落在 6-18 波 |
| 夜袭 | 该波敌人移速提升，但血量下降 | 落在 9-18 波 |
| 围攻 | 三通道同时开，但密度降低 | 落在 12-18 波 |
| 精英突袭 | 提前刷一只精英怪 | 落在 7-12 波 |

**事件不进 UI 列表**，只在发生时用一行飘字说明。理由同上：零操作游戏不能有说明书。

## 四·五、波次预告（2026-10-30 新增）

### 为什么现在必须补这一节

06 册 §3.2.0 之一已经拍板：**「散射 vs 双发」是玩家自负的抉择**——用户的原话是"遇到大面积低血敌人还选双发打定点导致失败，那是自己选择的问题"。

但这句话成立有一个**前提**：**玩家得先看得到下一波长什么样**。看不到，那不是选择，是抛硬币。同一逻辑还撑着另外两处决策：05 册的抗性（这一波要不要带减速/破甲）、Boss 波要不要留爆发。所以**预告不是锦上添花，是那几处决策的配套设施**。

### 三条不能破的约束（它决定了预告长什么样）

| 约束 | 来源 | 对本设计的限制 |
|---|---|---|
| **不在屏幕中央弹中文提示** | 用户既定偏好 | ❌ 不做居中 toast、不做弹窗、不做"即将来袭"大字 |
| **零操作游戏不能有说明书** | 本节紧邻的 §四 | ❌ 不给数字、不给列表、不给刷新时间点 |
| **P5 随手可撒手** | 00 册支柱 | ❌ 不要求玩家点开查看，信息必须常驻可见 |

结论：**它只能是一条常驻的、极窄的标签条 + 一行词组，不能有任何交互。**

### 呈现形式

| 位置 | 内容 | 说明 |
|---|---|---|
| **出怪带下方的一条窄标签条**（常驻） | 平时显示"下一波"，波次开始后切换为"当前波" | 非侵入层，宽度不超过出怪带，高度约一行字 |
| **选卡界面底部一行** | `下一波：成群 · 混编 · 含装甲兵` | 唯一真正做决策的地方必须给到——这是本节的核心诉求 |
| **Boss 波** | **提前一整波**给出警告标签 + 一次音效 | Boss 需要提前配 Build（要不要留爆发 / 换弹节奏），只提前一波不够，但也只提前一波——提前太多会让玩家全程围着 Boss 转 |

### 信息粒度：只给"形态标签"，不给数字

| 维度 | 取值（枚举，实现直接查表） | 给到什么程度 |
|---|---|---|
| **规模** | 小批 / 成群 / 潮水 | 决定"我要覆盖还是要单体"，直接支撑 06 册的散射/双发抉择 |
| **构成** | 单一 / 混编 + **最多 2 个类型图标** | 图标用 05 册已有的怪剪影，不加新美术负担 |
| **威胁** | 无 / 精英 / **BOSS** | Boss 用配色区分 |
| **抗性提示** | 只显示 Top 1（如"抗击退"） | 超过 1 个就变列表，会退化成说明书 |

**明确不给**：血量、数量、出现时间点、伤害数值、modifier 幅度。理由不是偷懒——**给了这些，玩家就不再"猜"，而是在读表**，3 选 1 的重量感会被稀释。

### 随机事件不预告（这条是本节的自我约束）

04 册 §四 的 5 个随机事件（尸潮突变 / 夜袭 / 围攻 / 精英突袭 / 空投）**一律不进预告**。

理由：那是**惊喜层**，预告会把惊喜变成日程表。而且像"尸潮突变"这种事件，本就是"把某一波敌人全部换成同一类型"——如果提前告知，形态标签会先于实际生效，逻辑上也自相矛盾。

### 失败信号（护栏，防止预告做过头）

| # | 信号 | 说明 |
|---|---|---|
| A | 玩家从不看这条标签 | 位置/尺寸不对。第一步先调可见性，**不要先加信息量** |
| B | 玩家看了仍选错 | 词不达意或粒度不够——通常是"规模"这一维失效 |
| C | 玩家开始**每波临时对策**、不再维持一个连贯 Build | ⚠️ **最危险的失败**：预告给太细了，玩家从"构建"退化成"应答"。若出现，第一动作是**降粒度**（砍掉抗性提示），而不是加信息 |
| D | Boss 波前玩家什么都没改 | Boss 提前量不够（把提前 1 波改成提前更多），或标签没引起注意 |

> 信号 C 是本节最该盯的一条。**预告的目的是让抉择有意义，不是让玩家每波重开一局构建。** 这也是"只预告下一波、不预告后三波"的原因——给准备，不给规划。

### 与其它分册的关系

| 分册 | 关系 |
|---|---|
| 06 册 §3.2.0 之一 | **首要服务对象**：散射/双发的"玩家自负"抉择依赖这一节的规模标签 |
| 05 敌人设计 | 标签的数据来源（抗性提示取自二·七的三条写死属性） |
| 14 怪物状态系统 | 状态标签与波次标签必须视觉区分（状态挂在怪身上，波次标签在出怪带），避免玩家混淆"这只被冻住"和"下一波有冰抗" |
| 03 卡牌系统 | 选卡界面是预告的**唯一高价值落点**，两处 UI 需一并做 |

## 五、Boss 与收尾

### 一章两个 Boss（第 5 关、第 10 关）

| 关 | 第 20 波形态 | 定位 |
|----|-------------|------|
| 1-4、6-9 | **最厚尸墙** | 综合检验：清群 + 续航 + 控场 |
| **5** | **中期 Boss** | 半成型 Build 的检验 |
| **10** | **章末 Boss** | 毕业考，全套 Build |

尸墙的设计全部保留：**最大密度混合尸潮、60+ 同屏、25-30 秒、清完为止**。
Boss 不是替换尸墙，是加在"每 5 关一次"的位置上。

### 尸墙为什么是最好的日常收尾

| | |
|---|---|
| 考的是综合 | 尸墙同时检验清群、续航、控场；单体 Boss 只检验爆发力 |
| 契合技能形态 | 这个游戏的技能是**独立攻击体系**（装甲车、射线、刀轮），价值都在"面"上 |
| 画面 | 满屏特效 + 满屏数字，是截图级画面 |

### ⚠️ Boss 必须改形态，否则会出现"背叛感"

> 一个纯单体的 Boss，会让铺面 Build 在最后一分钟突然失效。
> 那不是难度曲线，是背叛。

所以给 Boss 定四条硬约束：

| # | 约束 | 理由 |
|---|------|------|
| 1 | **必须持续召唤杂兵**，且杂兵构成随阶段变化 | 铺面 Build 全程有事可做，清杂兵不是白打工 |
| 2 | **散布在空间里**：多部位可分别破坏，或分阶段多个出场 | 让 AOE / 溅射 / 连锁类增益仍然成立 |
| 3 | **血量不能高到"打不动"** | 难点应该是"持续输出 + 处理杂兵"的**资源分配**。血条长只会让战斗变慢，不会让战斗变难 |
| 4 | **不免疫任何控制**（可减速、可击退、可被冻结） | 否则控场 Build 在这里直接作废 |

满足这四条之后，Boss 考的就不再是"你有没有单体爆发"，而是
**"你能不能一边维持清场，一边抽出资源打掉一个高价值目标"**——
这对所有 Build 都成立，且解法多元。

### 中期 Boss（第 5 关）有一个专属坑

> **第 5 关时玩家等级只有约 5，技能池只解锁了一半，Build 是半成型的。**
> 如果中期 Boss 的血量按"满 Build"配，它会变成一堵比章末还硬的墙。

处理办法（二选一或并用）：
- 中期 Boss 血量按**半成型 Build** 单独配一条曲线，不走章末 Boss 的缩放公式
- 或者：**第 5 关额外多给一次升级**（如多加到 21-22 次），明示"这是中场考核，给你加餐"

倾向第二条——它在叙事上更成立，而且不需要额外维护一条数值曲线。

### Boss 的内容量

一章两个 Boss × 后续章节 = 每章两个新 Boss。做第 1 章时只需 **2 个 Boss**，不算重。
但要注意：**第 2 章的 Boss 不能在机制上重复第 1 章**（同模型换皮会被立刻看穿），
建议每个 Boss 绑定一条专属机制（召唤 / 护盾 / 分裂 / 地形改变）。

### 目标优先级的完整规则

| 场景 | 锁定规则 |
|------|---------|
| 全部场景（含 Boss 波） | **永远锁"最近"**，无一例外 |
| 携带特定卡 | 优先某类敌人（自爆/远程/装甲） |

**"改目标优先级"仍然是一类武器卡**——它解决的是"我不想每次都手动点"，是**省力**而不是**必需**。
这个定位很重要：如果这张卡变成"必须带"，说明自动瞄准的默认规则错了。

### 为什么 Boss 波也绝不自动锁 Boss

```
如果自动优先锁 Boss
  → 玩家不需要手动接管
  → 手动接管在 Boss 战失去价值
  → 精英难度"手动是必需"这条（见第九节）落空
  → Boss 战退化成"站着看"
```

**Boss 战的核心决策，恰恰应该是"要不要把火力从杂兵身上挪到 Boss 身上"。**
自动帮玩家做了这个决定，Boss 就没了。

所以锁死：**自动瞄准永远锁最近。Boss 体型大 = 受击面大 = 它靠近时自然会吃到火力，
但这和"系统帮玩家选 Boss"是两回事。**

### 两个难度的 Boss 战要求

| 难度 | 要求 |
|------|------|
| **普通** | 不手动也能过，但会打得很险——**剩余血量 < 30%**。手动是"打得漂亮"，不是"能不能过" |
| **精英** | 手动接管是**事实上的必需**。手动水平直接决定能不能过 |

这条同时是 Boss 数值的配平依据：
**Boss 血量必须按"大部分火力打在杂兵上"来配**，而不是按"火力全打 Boss"来配。
直觉上会配得偏高，因为自动瞄准会吃掉一大半输出去清杂兵——这是有意的，不是 bug。

## 六、章节与关卡

| 项 | 规则 |
|----|------|
| 章节 | 先做 1 章，10 关 |
| 关卡难度 | 用**逐关显式系数**，不用线性公式 |
| 关卡差异 | 每关一个 modifier，改变的不是"更难"，而是"难在哪" |
| Boss | **每 5 关一次**：第 5 关（中期）、第 10 关（章末）。其余关第 20 波为尸墙 |

### 第 1 章 10 关的 modifier 草案

| 关 | Modifier | 想考的 Build |
|----|----------|-------------|
| 1 | 无（教学） | 无 |
| 2 | 密度提升 | 清群能力 |
| 3 | 自爆兵数量翻倍 | 单体爆发 / 目标优先级 |
| 4 | 远程兵提前出现 | 续航 / 反击能力 |
| 5 | **中期 Boss**（本关第 20 波）+ 精英怪血量提升 | 半成型 Build 的资源分配 |
| 6 | 全场敌人移速提升 | 控场（干冰弹 / 燃烧地带） |
| 7 | 飞行单位提前出现 | 覆盖面 |
| 8 | **要塞血量上限下降** | 惩罚"只堆输出"的 Build |
| 9 | 全类型混编 + 密度提升 | 综合 Build 完整度 |
| 10 | **章末 Boss**（本关第 20 波） | 全套 Build + 持续输出 + 控场 |

**第 8 关是这章最重要的一关**：它是唯一一关明确惩罚"纯输出流"的设计。
如果玩家在这关翻车，他会学到"要塞血量/控场也是 Build 的一部分"——这是整个游戏最重要的一课。

## 七、难度曲线（结构原则，不写数值）

1. **难度不能只靠敌人血量涨**。血量涨会让战斗变慢（更肉），密度涨会让战斗变紧（更慌）。后者才是这个游戏该有的紧张感。**以密度为主，血量为辅。**
2. **每关的平均难度必须略低于上一关的"最强一波"**。这样玩家会觉得"我变强了"，而不是"越来越难"。
3. **逐关显式系数，不用公式**。因为玩家强度增长是非线性的（卡池解锁是台阶式跳变），任何公式都会在某些关产生锯齿。
4. **第一关必须能过**。教学关劝退是这个品类最常见的死法。

## 九、精英难度

参考视频里有「普通 / 精英」两档。做，且定位为**重复游玩的主要动力**。

| 项 | 规则 |
|----|------|
| 解锁 | 该关**普通难度通关一次**后解锁该关精英难度 |
| 难度来源 | **不动 Build，只动关卡**：① 敌人血量/密度提升 ② 增加一个波次 modifier ③ 部分波次提前引入后期兵种 |
| 掉落 | 精英难度的碎片/材料产出显著提高，且**独占某些局外解锁物** |
| 不允许 | 精英难度不改变卡池规则——它考验的是玩家的操作与判断，不是抽到更好的牌 |

**为什么不动 Build**：20 次升级是这个游戏的全部深度来源。
如果精英难度给玩家更多/更强的卡，它就从"考你会不会玩"退化成"考你有没有更好的运气"。

### 精英难度与要不要挑战 manual 接管的关系

普通难度定下的验收标准是「全程不碰屏幕必须能通关第 10 关」（01 册）。
**精英难度把这条放宽**：允许它要求玩家使用手动接管（但不要求精度与手速——01 册硬约束仍在）。
这样两个难度的存在才各自成立——
普通难度是"看 + 决策"，精英难度是"看 + 决策 + 手"。

## 十、手动接管的教学时序

### 这个缺口是什么

B1（Boss 战要求手动）和 B4（专心深挖 2 条线）会**抢玩家的注意力**：
如果玩家在第 5 关中期 Boss 才第一次被迫手动，他一边要处理"我的 Build 还没成型"，
一边要现学"我还能点屏幕"——**两个新东西同时砸过来，这就是挫败感的来源**。

**补法：手动接管必须提前教，而且要在零压力时教。**

### 教学时序

| 关 | 场景 | 玩家会经历什么 |
|----|------|--------------|
| **第 1 关** | 出现"卡在出怪带最上沿不动"的敌人（如远程兵） | 自动瞄准锁的是最近的那个，玩家会眼睁睁看着远处的敌人一直输出。<br>**此时无需任何提示**——他自然会去点它，然后发现"原来我能点" |
| **第 2-3 关** | 同类场景出现 2-3 次，密度逐渐上升 | 手动接管从"发现"变成"习惯"。**仍然零提示** |
| **第 4 关** | 第一次出现"不手动会明显吃亏"的波次 | 玩家已经会了，只是第一次感受到它的价值 |
| **第 5 关** | **中期 Boss** | 手动接管成为核心决策。玩家此时已是熟手 |

### 关键：不要弹提示

这条时序成立的前提是**不弹任何教学提示**。
弹提示等于告诉玩家"你刚才玩错了"，而弹提示时玩家通常在忙着看卡牌。

**正确的做法是设计场景，不是设计教程。**
让"自动瞄不准"这件事自己暴露出来，玩家自己找到解法——
这个"啊，原来我可以点"的瞬间，比任何新手引导都记得住。

### 验收

第 1 关通关的玩家里，应有高比例在第 2 关就开始自发使用手动接管。
如果这个比例过低，说明"自动瞄不准"的场景设计得不够明显，要调远程兵的停留逻辑。
