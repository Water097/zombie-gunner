## 一、五条硬规矩

**规矩 1 · 手动接管只能纠正目标，不能提升输出**

```
管什么：玩家点屏幕时，改变的是"打谁"，不是"打多疼"
边界  ：验收 = 全程不碰屏幕，必须能通关第 10 关（普通难度）
反例  ：任何"点了之后伤害变高"的设计都是错的
```

**规矩 2 · Boss 战怎么平衡"撒手能过"和"Boss 有存在感"**

```
普通难度：不手动也能过，但会打得很险（剩余血量 < 30%）
精英难度：手动接管是事实上的必需
边界    ：自动瞄准永远锁"最近"，绝不自动优先 Boss
          （否则手动就没有价值，精英难度那条会落空）
Boss 本身：持续召唤杂兵 / 散布空间 / 血量不能打不动 / 不免疫任何控制
```

**规矩 3 · 每张卡必须有主语**

```
管什么：卡面文案
边界  ：禁止「伤害 +60%」这种没有对象的卡
        必须是「装甲车伤害 +60%」「子弹伤害 +60%」
判别  ：把卡面上的名词去掉之后还能看懂 = 不合格
效果  ：通用最优解自动消失，不需要额外 UI 解释
```

**规矩 4 · 什么时候停止发「学习新技能」卡**

```
管什么：抽卡池
公式  ：剩余升级次数 < 3 × 未成型技能数 + 4  →  池子里不再出现「学习新技能」
边界  ："未成型" = 该技能等级 < 3
        `+4` 是新技能的起步价余量（3 张成型 + 1 张缓冲）
效果  ：自然引导出「深挖 2 个技能」的甜区，不需要教玩家
```

**规矩 5 · 局外强度的上限**

```
管什么：武器品级 + 玩家等级 + 技能升级奖励 + 装备攻击词条，四者合计（仅输出侧，生存侧另算）
公式  ：局外输出侧倍率 ≤ ×2.0
边界  ：分母（终局期望倍率）固定取 ×5.0，不随玩家 Build 浮动
        → 实际占比 = (2.0-1) ÷ (5.0-1) = 25%
        → 敌血基准维持 ×1.0，全局数值尺度不动
硬线  ：> 40%（倍率 ×2.7 以上）即视为失控，不允许
分配（草案快照，数值阶段已 Monte Carlo 验证）：品级 ×1.22 × 等级 ×1.10 × 技能奖励 ×1.15 × 装备 ×1.30 ≈ ×1.99  （⚠️ 2026-10-30 终稿已重分：武器品级 ×1.30 / 装备攻击 ×1.20 / 合计 ×1.92，见 07 册七·五）
  （2026-10-30 **已拍板**：「技能奖励」项是 `eff = 1 + c×B` 的概率性项、非乘算。Excel 原值 +1.0%/级 × 152 次 = B152% 会在精确步枪超到 ×1.228、25% 枪 ×1.380；守 ×1.15 需 B≤60%(按 25% 上限枪)。**采纳 +0.30%/级**（B≈46% → @25% 枪 ×1.114），留出约 0.036 余量给未来的装备强化/镶嵌。详见 02 册 2.2 之一、07 册七·五）
备注  ：早期"局外绝不给攻击力"已于 2026-10-30 推翻——局外**可以给攻击**，但必须框在这 ×2.0 内（见 07 七·五、11 册局外攻击桶）
```

### 五条之间为什么不打架

| | 规矩 1 | 规矩 2 | 规矩 3 | 规矩 4 | 规矩 5 |
|---|---|---|---|---|---|
| 规矩 1 手动只改目标 | — | 互补（Boss 战是手动的主场） | 无关 | 无关 | 无关 |
| 规矩 2 Boss 平衡 | 互补 | — | 无关 | 见下方唯一接口 | 无关 |
| 规矩 3 卡带主语 | 无关 | 无关 | — | 无关 | 无关 |
| 规矩 4 停发新技能 | 无关 | 见下方唯一接口 | 无关 | — | 无关 |
| 规矩 5 局外上限 | 无关 | 无关 | 无关 | 无关 | — |

**唯一接口**：Boss 战要求手动（规矩 2），停发新技能又要求玩家专心养 2 条线（规矩 4）——
两个新东西同时砸过来会挫败。
**补法**：手动接管提前教，第 1-3 关用场景引导（远程兵停在出怪带最上沿），**不弹任何提示**。

## 二、站得住的判断（建议锁死，别再改）

| # | 判断 | 为什么站得住 |
|---|------|------------|
| A1 | **半自动瞄准：手动只能纠正目标** | 唯一能同时保住"省事"和"Build 有意义"的做法 |
| A2 | **每张卡必须带主语** | 比"限额 6 张"优雅：不需要 UI 解释，它自己就是约束。来自实测 |
| A3 | **技能 = 独立攻击体系** | 正因为各成体系，才能"在这条已经铺开的线上加倍投" |
| A4 | **选择 > 深度** | 把技能设计从"画一条深度曲线"变成"设计 20 级树各维度的差异化"。已落到 11 册 |
| A5 | **暴击不翻倍**（m = 1.3-1.5） | 翻倍暴击会让 Build 退化成"暴击 / 非暴击"两种 |
| A6 | **装备压到 6 个部位** | 9 个互不相干的格子不产生取舍，只产生比较疲劳 |
| A7 | **首饰走攻击词条池，但只给"局内机会"型词条** | 让攻击类装备每局价值不同（因为每局 Build 不同），而不是恒定的 +30%（参考 game：头盔/护臂/手套都带攻击词条，首饰同样可带，但机会型优先） |
| A8 | **Boss 每 5 关一个** | 每关有 Boss 会让收尾单一化，只有章末有则一章太长没有记忆点 |
| A9 | **出怪区限制在顶部横带、不超中线** | 顺手解决三件事：给"防线"物理定义、让"击退"有可见价值、腾出下半屏 |
| A10 | **移动端硬指标**（100dvh / 禁长按菜单 / 切后台暂停 / DPR≤2） | 唯一一组不值得讨论的规则，被大量项目验证过 |

## 四、已解决的坑（只留结论）

| # | 坑 | 结论 |
|---|----|----|
| B1 | Boss 可能和尸墙变成同一个东西 | Boss 的独有价值不是"血厚"，而是**考火力的动态分配**（一边清杂兵一边抽资源打高价值目标）。两个难度各守一端 |
| B2 | 低倍率暴击在数学上是陷阱卡 | m=1.35、c=50% 时期望仅 ×1.175，不如一张 +30%。→ 改触发器（R1+R2）；暴击率硬上限 **25%**；红字要做 0.3 秒跳字合并 |
| B3 | "后期武器数值更大" 与 "局外要给攻击力" | 用 ×2.0 上限框住（07 七·五、11 册局外攻击桶）：局外**可以给攻击**（技能升级奖励 + 装备词条 + 品级 + 等级），但四来源有界、乘积封顶 ×2.0。早期"局外绝不给攻击力"已推翻 |
| B4 | 学技能的时机变陷阱 | `剩余次数 < 3 × 未成型技能数 + 4` → 停发新技能卡。连带后果已接受：第 11 级之后基本不再开新线 |
| B5 | 台词工作量被低估 | 首版只做 3 种敌人；每句 ≤ 12 字（气泡超过两行会盖住战场） |
| B6 | 出怪区收窄后下半屏空了 | 机会：技能栏/Buff 栏/飘字放下半屏不再挡战场。坑：画面头重脚轻 → 并入阶段 3 场景设计 |
| B7 | 稀有度命名 | 灾厄 = 赤红 + 黑纹；传说 = 金（上移让位）。**「史诗」不许排在「传说」后面** |


第 2 步听起来很小，但它是整个设计里质量最高的一页——
**如果一个技能说不出"它和其他技能的正确投法有什么不同"，那它就不该进这 8 个。**
