## 七、纪律（改之前先看，别回退）

- 每张卡必须带**主语**，文案必须说清"加的是哪一项"（"【子弹】伤害 +60%" 合格，"【子弹】+60%" 是废文案）
- 同桶**加算**不连乘；弹道/连发是独立乘数，不进 % 桶
- 条件卡强度 ≈ 无条件卡的 1.5~2 倍（补偿覆盖率），否则没有拿的理由
- 状态施加只走 `apply`，伤害只走 `dealDamage`（飘字标注、装甲车门禁、DoT 都在这一处）
- **渲染层角度 = 内核 atan2 角**（0=+x、π/2=+y，`dx=cos, dy=sin`）。概念图 `skills.mjs` 的扇面用「0=正上」的 `x=sin, y=-cos` 换算，那是**画廊自己的坐标系**，整块搬进 demo 会差 90°（制导激光曾因此往左下/底部扫）。演出时钟用实例自身存活时间，别用全局 `world.time`（光束会周期性熄灭）。判定用的几何量（扇面半角 / 火区椭圆 / 车身尺寸）渲染必须读同一个字段，别再制造「所见非所受」
- **局部 -y = 弹头 / 枪口朝向**：要把它对到标准 atan2 角 `ang`，必须 `rotate(ang + π/2)`；只 `rotate(ang)` 会让弹体横过来（干冰/温压弹曾因此水平）。枪口方向只能由目标决定（`turretShots.tx/ty` 或最近敌人），**不许用 `sin(time)` 摆动**
- **技能演出进度用实例 `1 - life/maxLife` 归一化**：闪电/爆炸是一段「闪现→命中→消失」的时序，不是一张挂在那儿渐隐的静图；折线 seed 必须逐帧变化才会「闪」。实机 280ms 就是「快」，实验室把 maxLife 拉长即可逐拍看清，同一份渲染代码不用改
- `.workbuddy/` 是本地记忆目录，**在 `.gitignore` 里**；对外可见的记忆镜像在仓库 `memory/`，改完记忆跑 `node scripts/memory-sync.mjs` 再提交（换机器用 `--pull` 还原）
- 提交走 SSH（Water097 已认证），改完直接 `commit` + `push`，不建 bat 脚本
