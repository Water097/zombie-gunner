## 二、阶段 1 · 考卷（敌人 / 武器 / 装备）

### 为什么这三样最先

技能名单已经定了，它就是**玩家的 9 种答卷**。
但在知道"考卷是什么"之前，我们无法判断这 9 份答卷够不够用。

```
敌人 = 考卷（玩家会被考什么）
武器 + 技能 = 答卷 A
装备 = 答卷 B（局外，决定他从哪开始答）
```

**先定敌人，再定武器。** 反过来做的话，容易做出"什么都能打的武器"，敌人就失去区分度。

### 1.1 敌人设计（05 册补全）— ✅ 已完成 2026-10-30

| 项 | 内容 |
|----|------|
| **产出** | 每种敌人的：外形一句话 / 行为逻辑 / 考哪项 / 死亡表现 / 台词（3 种） |
| **依赖** | 04 册波次表（已有）、02 册技能名单（已有） |
| **要定的** | 7 种敌人的**机制细节**（不只是名字）；精英怪与 Boss 的行为；敌人与"中线警戒线"的交互 |

**现有 8 种**：普通兵 / 疾行兵 / 自爆兵 / 远程兵 / 装甲兵 / 飞行兵 / 分裂兵 / **蜂群**

#### ✅ 1.1 已完成：覆盖率表填完了，结论是"加 1 种"

| 结果 | 数量 | 技能 |
|------|------|------|
| 有明确反面考题 | 3 | 高能射线 / 燃烧地带 / 旋转刀轮 |
| 需写死敌人属性才有 | 3 | 干冰弹 / 装甲车 / 哨戒机 |
| **完全缺失（早期）** | **2** | **温压弹 / 电磁穿刺**（都缺"散开"型敌人） |
| （末补）同一蜂群缓解 | 1 | **制导激光**（窄扇面扫射，蜂群铺太开仍难全扫，10 级扇面 +200% 后缓解） |

→ 补入第 8 种敌人「**蜂群**」：出生即散开、血量极低、成片推进。
**它把 9 个技能劈成两半**（克 5 个、被 3 个克），是全套敌人里唯一一个"能测出你 Build 宽度"的考题。

**详见 05 册二·五、二·六节。**

**这一步最重要的工作不是加新怪，是检查覆盖率**：

| 技能 | 它强在哪 | 有敌人专门考它的反面吗 |
|------|---------|---------------------|
| 温压弹 | 清群 | 需要"分散"型敌人让它难受 |
| 干冰弹 | 拖延 | 需要"免疫减速"或"数量极多"的敌人 |
| 电磁穿刺 | 打队列 | 需要"散开"型敌人 |
| 高能射线 | 持续输出 | 需要"高血量单体"让它显得慢 |
| 装甲车 | 击退 | 需要"免疫击退"的敌人（装甲兵） |
| 哨戒机 | 覆盖 | 需要"绕过炮台"的敌人（飞行兵） |
| 燃烧地带 | 封锁 | 需要"快速通过"的敌人（疾行兵） |
| 旋转刀轮 | 横向清场 | 需要"高空"敌人（飞行兵）让它够不到 |
| 制导激光 | 窄扇面清线 + 聚焦清要点 | 需要"大量散开低血目标"让它来不及扫（蜂群，10 级后缓解） |

**这张表填不满，就说明敌人不够用**——那时候才该加新怪，而不是现在拍脑袋加。

### 1.2 武器设计（06 册补全）— 🔧 设计完成，数值已校准（2026-10-30 落 ×2.0 账）

| 项 | 内容 |

| **依赖** | 1.1（敌人定完才知道需要什么火力形态） |
| **产物落在** | **06 册二·五**（六桶归属）+ 第三节（卡池结构 / 弹道卡过滤 / 旧卡去向） |

#### 已完成的内容

**六桶定义**（W1-W6）：常驻 / 装填（换弹后前 6 发）/ 远距 / 近距 / 持续（连射 10 发）/ 首发。

**第 0 条决策：状态桶移出武器侧。**
「对冻结目标 +X%」的前提是技能 Build，主语应该是技能不是武器（06 册第一节分工纪律的直接推论）。
→ 武器卡的强度只由枪自己决定，新手不会被塞废卡。

**归属矩阵**（每把枪只有一个主场桶）：

| 枪 | 主场桶 | 手感 |
|---|---|---|
| 突击步枪 | **W1 常驻**（唯一） | 稀释最快 → 上限最低。新手枪该有的样子 |
| 冲锋枪 | W2 装填 | 换弹最频繁，窗口反复触发 |
| 霰弹枪 | W4 近距 | **敌人越近它越强** |
| 精确步枪 | W3 远距 | **前半场强，过中线后掉档**（与霰弹枪镜像） |
| 榴弹炮 | W6 首发 | 弹夹 5 发，前 2 发占 40% 机会 |
| 加特林 | W5 持续 | 前 10 发是弱期，与射速渐增同构 |

**隐藏的第七列 · 换弹惩罚率**（加特林 7.7% → 榴弹炮 24.2%）：
惩罚重的枪单发必须更狠，惩罚轻的枪单发必须更软。**排序不许改。**

**每把枪 3 张卡 = 6 级**：常驻 %（×3，突击步枪 ×5）+ 主场条件 %（×2）+ 物理参数（×1）。
与 10 册实测「武器 6 级 + 装甲车 7 + 射线 5」正好对上 → 反证容量是对的。

#### 遗留（挂在 06 册待定）
第 6 档品级的「独占机制」各枪给什么 → **6 枪全定且数值已校准**（2026-10-30：削 3 强 ＋ 账本重分，M 目标 ×1.13~1.18，见 06 册「数值校准」块）。
