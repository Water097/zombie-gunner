技能实验室 · 9/9 逐个测试

用 Demo 实机同一份渲染层（src/demo/skill-art.mjs）＋真实 SKILLS 参数驱动一份可控的测试 world。不用抽卡、不用等 CD、没有怪物干扰：每个技能都能立刻、反复、干净地看完整演出。参数取自 combat-core.mjs，改数值这里会自动跟着变。

→ Demo 实机 → 概念图库
怎么看方向对不对：黄色虚线是「发射点 → 目标」的目标轴，目标在正上方。制导激光 / 高能射线 / 干冰弹 / 温压弹都应沿这条轴往上打；装甲车从下方往上碾；旋转刀轮横向滚。黄色虚线可在上方关掉。

快捷键

  • 1–9：切到对应技能（按技能序号）
  • 空格：暂停 / 播放
  • R：重播当前演出

这一页测什么

  • 技能形态是否读得出来（不再是一个球换颜色）
  • 方向 / 朝向是否贴合玩法（目标轴 + 敌人剪影作参照）
  • 所见即所受：扇面半角、火区椭圆、车身判定框
  • 九宫格 = 之前 02 册 §2.7 的「同屏叠加可读性」压测

渲染函数、色阶、演出逻辑全部来自 skill-art.mjs；这里只负责造实体与推进时间，没有第二套画法。
